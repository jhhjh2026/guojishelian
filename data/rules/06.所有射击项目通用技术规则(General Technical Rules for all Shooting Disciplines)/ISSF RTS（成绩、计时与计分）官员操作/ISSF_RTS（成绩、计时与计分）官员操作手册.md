# ISSF RTS 官员操作手册 (RTS Officers Manual)

> **标准依据**：本手册依据国际射击运动联合会《通用技术规则》（*ISSF General Technical Rules, Edition 2025 (Second Print 07/2026), Effective 1 July 2026*）第 6.8 节（RTS 仲裁职责）、第 6.9.3–6.9.4 节（CRTSO/RTSO 职责）、第 6.10 节（EST 计分操作）、第 6.14–6.16 节（计分、同分破平与抗议）及《ISSF RTS 官员指南》整理编制，系统规范成绩、计时与计分办公室（RTS Office）在赛前数据库联调、赛中 EST 实时数据流监控、串靶/漏发/多余弹处理、物理物证复核（EST Challenge）、成绩倒推算法执行、决赛出发名单生成及官方成绩册（Results Book）三方会签等全流程法定作业程序。

## 二、赛前准备、数据库核验与系统联调 (Pre-Competition Verification)

### 2.1 基础数据导入与运动员核验
1. **名单与 ISSF ID 校验**：从 ISSF 官方报名系统（Entry System）全量导入名单，100% 核对姓名拼写、国籍 IOC 代码、性别、组别（成年/青年）及唯一 **ISSF ID**；
2. **RPO 选手标记（Rule 3.7.5.4）**：在系统中为每协会超出 3 人的额外选手准确标注 **`RPO`（仅计世界排名积分）** 标识，锁定其不得占用决赛晋级席位；
3. **出发名单（Start Lists）生成**：
   - 步手枪资格赛：计算机随机分配靶位与轮次（Relay），生成官方《资格赛出发名单》；
   - 经 RTS 仲裁主席及技术代表（TD）签字后，赛前至少 24 小时向全体代表团公示。

### 2.2 EST 系统时钟与硬件联调（Rule 6.10.3）
- **时钟统一校准（NTP）**：确保全场电子靶主控服务器、射击位监视器、记分大屏及电视转播时钟与 GPS 标准时间实现毫秒级同步；
- **每轮赛前强制状态核查**：协同靶务官（Target Officers）核对每块电子靶：
  - 靶面白色区域无遗留弹孔，靶框旧弹痕已涂黑标记；
  - 衬卡（Backing Card）、衬靶（Backing Target）及控制纸（Control Sheet）已全量推进至全新覆盖区。

## 三、赛中实时数据监控与异常处置规程 (Live Monitoring & Incident Handling)

```
                            【赛中 RTS 异常事件处置流线】
                                          │
            ┌─────────────────────────────┼─────────────────────────────┐
            ▼                             ▼                             ▼
   【靶面单发未显示/漏记】              【串靶 (Cross-fire)】          【多余弹 (Extra Shots)】
   • 立即指示原靶补发 1 发             • 调取相邻靶 LOG 日志          • 核查当姿/当组发数上限
   • 记录补发弹为受质疑弹              • 判定认领方与受害方          • 超出发数一律作废不计
   • 轮次结束后启动物证复核            • 受害方补射/不计入该弹        • 依据 6.12 处以相应罚分
```

### 3.1 单发弹未在屏幕显示处理（Rule 6.10.9.3–6.10.9.4）
1. **补发指令与记录**：靶场官员接报后，指示选手向原靶补射 1 发比赛弹（MATCH Shot），RTS 监控端将该补发弹标记为待核验受质疑弹；
2. **赛后判定流程**：
   - 若原始受质疑弹在底层数据或控制纸上被找到 ➔ 原始弹成绩计入，补发弹成绩计入，**作废最后发射的一发（超出总数的一发）**；
   - 若原始受质疑弹完全未找到且无系统故障证据 ➔ 原始弹判定为脱靶（0 分），作废最后发射的多余发；
   - 50m / 300m 项目若无脱靶证据，RTS 仲裁可认定系统硬件丢包，以补发弹成绩替代计入。

### 3.2 串靶（Cross-fires）与多余弹处置标准（Rule 6.11.2 / 6.11.3）
- **串靶处理**：
  - 发射者（打错靶方）：该发弹判定为脱靶（0 分），若打在他人靶上，该弹从其本人成绩中记为 0 环；
  - 被打者（受害方）：他人误射的弹着在 RTS 系统中直接剥离作废，受害者继续完成其规定发数；若无法区分弹着，指令受害者补射该发；
- **三姿换姿未切换 SIGHTING（Rule 6.10.4 c）**：
  - 运动员换姿后疏忽未切回 SIGHTING，在前一姿势中被记录为 extra shots 的成绩**一律由 RTS 仲裁在系统中直接作废（Void）**，并将靶面重置。

## 四、物理复核与测量操作规程 (EST Challenge SOP)

当选手提出分值抗议（Rule 6.10.7）或发生漏弹争议时，RTS 仲裁必须启动法定物证复核：

```
                      【EST 物理物证链条法定收集清单】
  ┌────────────────────────────────────────────────────────────────────────┐
  │ 1. 靶位 LOG 日志打印件 (Target Raw Log Printout，含 X/Y 坐标与时间戳)    │
  │ 2. 控制纸 (Control Sheet，25m/50m 用于精确定位实际弹孔中心)             │
  │ 3. 衬卡 / 衬靶 (Backing Cards / Backing Targets)                       │
  │ 4. 黑色纸带 (10m) / 黑色橡胶带 (50m) 物理弹痕截段                      │
  │ 5. 靶场事件报告单 (Form IR - Range Incident Report)                    │
  └────────────────────────────────────────────────────────────────────────┘
```

1. **光学对位规测量（Optical Alignment Gauge）**：
   - 将取下的控制纸平铺于测量台上，使用经 ISSF 认证的光学对位规，以控制纸基准定位点为基准，精确测定物理弹孔的实际几何坐标；
2. **底层日志与几何坐标比对**：
   - 将物理测量坐标与 EST 计算机底层日志中的 X、Y 原始传感器数据比对；
3. **裁决与罚分应用**：
   - **抗议成立（系统误差）**：RTS 仲裁签署《成绩修正单》，在服务器端更新正确分值；
   - **抗议驳回（原判正确）**：维持系统原始分值，**并从该运动员受质疑当组（或第一组比赛弹最低分）中扣除 2 环罚分（Rule 6.10.5 c / 6.10.7 d）**。

## 五、同分破平算法与倒计数规则执行 (Tie-Breaking Execution)

资格赛结束时，RTS 计算机系统必须严格依据 **Rule 6.15** 预设算法自动打破同分，严禁人工随意调整：

### 5.1 小数计分项目破平逻辑（10m 气步枪、50m 卧射 - Rule 6.15.1 f）
```
  [ 比较总成绩 (小数) ] 
          │ (相同)
          ▼
  【第 1 步】比较最后 10 发组小数总分 ────► 分高者胜 (仍相同向前逐组倒推：倒数第2组、第3组...)
          │ (全部10发组完全相同)
          ▼
  【第 2 步】比较最后一发单发小数分值 ────► 精确分高者胜 (仍相同向前逐发倒推：倒数第2发、第3发...)
          │ (所有单发小数完全相同)
          ▼
  【第 3 步】最终平分：名次并列 ──────────► 成绩册按运动员姓氏拉丁字母升序 (Alphabetical Order) 排列
```

### 5.2 整环计分项目破平逻辑（10m 气手枪、50m 步枪三姿、25m 各项目 - Rule 6.15.1 a–e）
```
  [ 比较总成绩 (整数) ]
          │ (相同)
          ▼
  【第 1 步】比较全场内十环总数 (Inner Tens / * / X) ────► 数量多者胜
          │ (仍相同)
          ▼
  【第 2 步】比较最后 10 发组整环总分 ───────────────────► 分高者胜 (不计内十与小数，向前逐组倒推)
          │ (全部整环组完全相同)
          ▼
  【第 3 步】逐发倒推内十环 ─────────────────────────────► 从最后一发向前比，内十环 (X) > 普通 10 环
          │ (仍相同)
          ▼
  【第 4 步】逐发倒推单发小数精确环值 (EST) ─────────────► 从最后一发向前逐发比单发小数精确值
          │ (仍相同)
          ▼
  【第 5 步】最终平分：名次并列 ─────────────────────────► 成绩册按运动员姓氏拉丁字母顺序排列
```

## 六、决赛出发名单生成与号牌分配 (Finals Start Lists)

1. **晋级名单生成（8 人决赛制）**：
   - 资格赛结束后，RTS 系统锁定前 8 名选手晋级决赛；
   - 若出现争夺第 8 名晋级资格的同分：
     - **步手枪项目**：依据上述 Rule 6.15 倒推算法直接决出晋级者与第 9、10 名递补（Reserve）选手，**绝对不组织现场加赛**；
     - **飞碟项目**：若回溯法遇绝对平局，触发加赛（Shoot-off），加赛结束后将最终名次录入 RTS 系统。
2. **决赛起始号牌与靶位分配（Rule 6.17.1.2 & 9.17.2）**：
   - **步手枪个人决赛**：计算机系统进行靶位随机抽签（A 至 H），生成《决赛出发名单》；
   - **飞碟个人决赛**：按资格赛/加赛排定位次分配 **1 至 8 号起始号牌（Bib Numbers 1–8）**（第 1 名佩戴 1 号，用于 3–8 名淘汰平局直接判定）；
   - **25米手枪速射（男子）**：按资格赛排位赋予 **1 至 8 号起跑号**，分配至 A-B / C-D 三级轮转靶位。

## 七、临时成绩公示、抗议期与官方成绩册签发 (Results Book Protocol)

```
                            【成绩发布与法定抗议时间线】
                                          │
   【临时成绩 (Unofficial Results) 发布】  ├── 成绩大屏与官方网站即时推送，标注打印时间戳
                                          │
   【法定抗议窗口期 (Protest Time)】      ├── 资格赛：公示后 10–20 分钟 (依据赛事规程)
                                          ├── 决赛：比赛进行中即时抗议 / 终局前裁决
                                          │
   【抗议期满且无异议】                  ├── 仲裁主席宣布 "RESULTS ARE FINAL"
                                          │
   【官方成绩册 (Official Results) 签发】 └── CRTSO ＋ RTS Jury ＋ 技术代表 (TD) 三方会签
```

1. **临时成绩单（Unofficial Results）公示**：
   - 包含运动员排位、姓名、国籍、分站/分组成绩、总分、内十环数、破平标记；
   - 成绩单下方必须清晰注明：**“PROTEST TIME EXPIRES AT [HH:MM]”**（抗议截止时间）。
2. **官方成绩册（Official Results Book）终审签发**：
   - 待所有成绩抗议审理完毕且抗议期满后，由系统生成正式官方成绩册；
   - **法定三方联合签署生效**：
     1. 主 RTS 官（Chief RTS Officer）
     2. RTS 仲裁委员会主席（RTS Jury Chairperson）
     3. ISSF 技术代表（Technical Delegate, TD）
   - 签署完毕后，官方成绩即具终局法律效力，上传至 ISSF 官方中央数据库并分发各参赛代表团。

## 八、RTS 官员操作速查与工作流检查总表

| 阶段 / 任务 | RTS 核心操作规范 | 质量控制与红线要求 | 对应条款 |
| :--- | :--- | :--- | :--- |
| **赛前数据导入** | 校验 ISSF ID，核实国籍与组别 | 准确标记 **RPO 选手**，锁定不占决赛席位 | Rule 3.7.5.4 |
| **系统底层日志** | 严禁未经授权点击 CLEAR LOG | 必须由 **RTS 仲裁现场监督** 方可执行日志清空 | Rule 6.10.8.3 |
| **漏射/丢包处置** | 指示原靶补射 1 发 Match shot | 赛后调控制纸与日志核验，多余发作废 | Rule 6.10.9.3 |
| **串靶数据剥离** | 调取相邻靶时戳日志，作废打错发 | 射错方判 0 分，受害方补齐有效发数 | Rule 6.11.2 |
| **计分抗议复核** | 使用光学对位规测量控制纸物理坐标 | 复核原判正确维持原分，**处 2 环罚分** | Rule 6.10.7.d |
| **资格赛破平** | 严格运行 6.15 预设算法自动破平 | 步手枪严禁加赛；自动排定前 8 席与递补 | Rule 6.15.1 |
| **决赛号牌分配** | 飞碟/速射按资格赛排名分配 1–8 号 | 号牌用于决赛 3–8 名淘汰平局直接裁定 | Rule 9.17.2.1 |
| **成绩册签发** | 抗议期满后生成，必须**三方签字** | **CRTSO + RTS Jury + TD 联合签署**生效 | Rule 6.8 / 6.9.3 |
