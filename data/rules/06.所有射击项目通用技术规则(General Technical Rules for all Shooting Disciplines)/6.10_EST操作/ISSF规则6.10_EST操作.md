## 二、赛前强制检查、控制纸覆盖与硬件联调 (Pre-Competition Verification)

### 2.1 仲裁委员会赛前强制检查四项清单（Rule 6.10.3）
每轮（Relay）比赛开始前，RTS 仲裁必须协同靶务官对全场每块电子靶逐一执行以下四项检查：
1. **靶面白色区域**：确认白色前挡板区域无任何遗留弹孔；
2. **靶框旧弹痕**：确认靶框外沿所有历史弹痕均已用黑色记号笔或标贴清晰覆盖涂黑；
3. **控制纸（Control Sheet）完全更新**：确认控制纸电机已将纸带推进至全新空白覆盖区（适用于 25m / 50m）；
4. **衬卡与衬靶状态**：确认衬卡（Backing Card）与衬靶（Backing Target）在控制纸中心覆盖区之外无历史遗留弹孔。

## 三、运动员监视器控制、换姿与显示屏管理规范 (Rule 6.10.4)

### 3.1 靶面显示模式切换（SIGHTING 与 MATCH 切换控制）
* **10m / 25m / 50m 单一姿势项目（Rule 6.10.4 a–b）**：
  * 由靶场主管通过主控计算机统一发出指令，全场同步从瞄准（SIGHTING）切换至比赛（MATCH）。
* **50m 步枪三姿项目（Rule 6.10.4 c）**：
  * 运动员完成跪姿或卧姿发射后，**由运动员本人自行在射击位监视器上按键切换** SIGHTING 与 MATCH；
  * 换姿后瞄准弹不限量、不加时；
  * **换姿疏忽红线**：若换姿后运动员**疏忽未切回 SIGHTING 模式**而在 MATCH 模式下击发，在前一姿势中被记录为多余弹（Extra Shots）的成绩**一律由仲裁在系统中作废（Void）**，裁判立即将靶面重置为 SIGHTING。

### 3.2 监视器屏幕与打印机管控纪律（Rule 6.10.4 d–f）
* **显示屏可见性**：整块射击位监视器屏幕必须保持完全可见，**严禁悬挂毛巾、衣物或任何物品遮挡视线**；
* **严禁擅动打印机**：赛程结束前，运动员与非授权裁判严禁按动打印机走纸键或面板；
* **成绩确认签字**：运动员在轮次结束后，须在打印条总分旁签字确认；未签字离场者由裁判或仲裁签注送交 RTS 办公室。

## 四、瞄准弹投诉、纸带故障与分值抗议处置 (Rule 6.10.5–6.10.7)

### 4.1 瞄准弹期间投诉靶面计分（Rule 6.10.5）
1. 运动员在瞄准弹阶段认为靶面计分异常举手报告；
2. 仲裁到场后可将运动员移至备用射击位，并给予相应补时；
3. 仲裁对原靶启动物理复核程序；
4. **败诉处罚**：若经复核确认原靶计分完全正常，**从该运动员资格赛第一组比赛弹最低分中扣除 2 环罚分**。

### 4.2 走纸/走带机构停止推进故障（Rule 6.10.6）
1. 经裁判及仲裁确认黑色纸带（10m）或黑色橡胶带（50m）因机械卡阻停止推进；
2. 立即将运动员移至备用射击位；
3. 允许发射不限量瞄准弹，并在备用靶上补打仲裁确定的有效比赛发数；
4. 赛后由 RTS 仲裁将第一块靶正常记录的成绩与第二块靶的补打成绩进行合并评定。

### 4.3 正式比赛弹分值抗议（Rule 6.10.7）
1. **时限要求**：分值抗议必须在下一发击发前（或最后一发击发后 3 分钟内）正式提出；
2. **复核流程**：轮次结束后调取该靶位及相邻靶位的 LOG 底层传感器日志与物理物证；
3. **败诉处罚**：若 RTS 仲裁复核判定系统显示分值准确无误，**维持原判并在该运动员受质疑当组中扣除 2 环罚分（Rule 6.16.5.2 c）**。

## 五、计分抗议后的 EST 物理复核法定规程 (EST Challenge SOP - Rule 6.10.8)

当发生计分抗议或单发弹未显示时，RTS 仲裁必须启动法定物证调取与物理复核：

```
                      【EST 物理物证法定调取链条清单】
  ┌────────────────────────────────────────────────────────────────────────┐
  │ 1. 靶位 LOG 日志打印件 (含传感器声学/光学时间戳及 X/Y 轴原始坐标值)     │
  │ 2. 控制纸 (Control Sheet，25m/50m 用于精确测定实际物理弹孔中心)         │
  │ 3. 衬卡 / 衬靶 (Backing Cards / Backing Targets，25m/50m/300m)          │
  │ 4. 黑色纸带截段 (10m) / 黑色橡胶带截段 (50m)                           │
  │ 5. 靶场事件报告单 (Form IR - Range Incident Report)                    │
  │ 6. 电子计分靶底层主控计算机原始数据库记录                              │
  └────────────────────────────────────────────────────────────────────────┘
```

### 5.1 光学对位规（Optical Alignment Gauge）测量 6 步法定 SOP
1. **物证封存取样**：靶务官在 RTS 仲裁监督下拆卸控制纸卷或衬卡，立即装入带有靶位号与轮次签注的物证袋；
2. **基准孔光学标定**：将控制纸平铺于专业透光测量台（Light Table），将光学对位规基准十字丝与控制纸上的出厂机械定位基准对齐；
3. **弹孔几何中心捕捉**：通过光学对位规的高倍放大物镜（10x 至 20x）捕捉弹孔破裂边缘，取几何外接圆拟合求出物理弹孔中心（X, Y 坐标，精度达 0.01 毫米）；
4. **环值物理半径换算**：依据各项目靶纸标准环值半径公式，计算物理弹孔中心至靶心的绝对几何距离；
5. **底层时间戳与坐标比对**：调取 EST 计算机中该发弹击发瞬间的 LOG 传感器原始数据（Time of Flight / Laser Array Data），核实系统记录坐标与物理测量坐标差值是否在允许误差（小于等于 0.10 毫米）以内；
6. **裁决签署与日志锁定**：
   - **系统误差成立**：由 2 名 RTS 仲裁联合签署成绩修正单，修正分值；
   - **原判正确（驳回）**：维持原判并处扣 2 环；**严禁私自点击 CLEAR LOG**，所有复核记录归档备查。

## 六、EST 故障分类与单发未显示处置流线 (Rule 6.10.9)

                                       │
                         【裁判指示选手向原靶补射 1 发】

             ┌─────────────────────────┴─────────────────────────┐
             ▼                                                   ▼

             │                                                   │

             │                                            2. 允许发射不限量瞄准弹；
   ┌─────────┴────────────────────────────┐               3. 步手枪选手重打未登记的 2 发比赛弹。
   ▼                                      ▼
【原始受质疑弹被找到/定位】              【原始受质疑弹未找到 / 判定为脱靶】

### 6.1 单发未显示（Non-registered Shots）4 大类场景物证判定矩阵
| 现场调查情况 | 控制纸 / 衬卡物证状态 | 底层传感器 LOG 日志 | RTS 仲裁最终法定裁决 | 成绩记录方式 |
| :--- | :--- | :--- | :--- | :--- |
| **场景 A：系统未显但弹孔存在** | 控制纸上找到清晰物理弹孔 | 日志中捕捉到微弱信号或硬件丢包 | **抗议成立（认定击中）** | 计入原始受质疑弹物理测量环值，作废多打的最后 1 发 |
| **场景 B：选手脱靶（Miss）** | 控制纸及靶面黑色区域无弹孔 | 日志无信号，靶框/背景板无痕迹 | **判定脱靶（0 环）** | 原始弹记 0 环，作废最后发射的多余发 |
| **场景 C：串靶发射（打错靶）** | 本靶无弹孔，相邻选手靶出现多余孔 | 相邻靶 LOG 显示相同击发时间戳 | **判定发射者 0 环** | 射错方记 0 环；受害方剔除该弹并补射有效发数 |
| **场景 D：50m/300m 传感器丢包**| 室外环境风噪导致声学未触发 | 控制纸推进故障无法取证 | **认定系统故障** | 以补发弹成绩替代计入受质疑弹分值 |

### 6.2 全靶场与单靶故障时间补偿标准
* **全靶场系统故障中断（Rule 6.10.9.1）**：
  * 故障排除恢复后，**比赛剩余时间统一追加 5 分钟**；
  * 恢复前**提前至少 5 分钟通过广播宣布**恢复时间，允许选手在这 5 分钟内回位准备；
  * 重新开始比赛弹射击前，允许发射不限量瞄准弹。
* **单靶硬件故障（Rule 6.10.9.2）**：
  * 若单靶故障在 5 分钟内无法排除，立即移至备用射击位；
  * 移位就绪后，**该选手比赛剩余时间追加 5 分钟**，并允许发射不限量瞄准弹。
* **移动靶单发未显示特别规定（Rule 6.10.9.5）**：
  * 给予选手 **2 分钟** 恢复准备，允许发射 **2 发额外瞄准弹**；
  * 随后在备用靶上重打未显示的 2 发比赛弹。

## 七、25 米项目电子靶灯时序公差与技术规范 (25m Target Lights Specification)

25 米手枪速射及运动手枪项目采用红绿电子靶灯（Green/Red Target Lights）代替机械翻转靶，其时序控制必须符合以下法定技术公差：

```
                      【25米手枪速射 5 靶联动靶灯时序控制】
  ┌────────────────────────────────────────────────────────────────────────┐
  │ 1. 预备信号 (ATTENTION)：红色靶灯亮起 (持续时间 7.0 秒 正负 0.1 秒)    │
  │ 2. 射击信号开始：红色熄灭，绿色靶灯瞬间点亮 (时差小于等于 0.01 秒)      │
  │ 3. 射击组时限 (8s / 6s / 4s 组)：绿色靶灯常亮时间公差为 +0.10s / -0.00s │
  │ 4. 组时限结束：绿色熄灭，红色点亮；绿灯熄灭后击发判定为逾时（扣除命中） │
  └────────────────────────────────────────────────────────────────────────┘
```

* **靶灯安装位置**：红绿 LED 信号灯必须安装在每块 25 米 EST 靶面正上方或两侧，确保光线强劲且不产生刺眼眩光；
* **毫秒级同步性**：同一组 5 个靶位的绿灯点亮与熄灭时间差**不得超过 0.01 秒**。

## 八、全靶场断电与网络崩溃应急处置预案 (Blackout & Disaster Recovery)

```
                            【全场断电/网络崩溃应急处理流线】
                                          │
   【突发断电/主控崩溃】 ───────────────► 靶场 UPS 不间断电源无缝接管 (维持至少 30 分钟)
                                          │
   【现场执法指挥】     ───────────────► 靶场主管立即口令宣布 "STOP - UNLOAD" (停止 - 退弹)
                                          │
   【底层数据紧急镜像】 ───────────────► 工程师从各靶位本地闪存 (Local Flash) 导出最后发数
                                          │
   【系统恢复与重启】   ───────────────► RTS 仲裁比对数据库 ➔ 提前 5 分钟广播 ➔ 剩余时间加时 5 分钟
```

1. **UPS 应急电源要求**：举办 ISSF 锦标赛的靶场，EST 核心交换机、服务器与射击位监视器必须配备在线式 UPS，确保全场断电时系统稳定运行至少 30 分钟以上；
2. **靶位本地存储机制（Local Memory Backup）**：官方认证的 EST 设备必须具备独立靶位脱机存储芯片，在网络彻底中断时自动缓存至少 200 发射击的原始传感器坐标与时间戳，严防数据因网络故障丢失；
3. **数据恢复核验**：网络恢复后，主 RTS 官（CRTSO）比对本地数据与中央服务器数据一致性，确认无误后方可恢复发射。

## 九、EST 常见违规与判罚速查对照总表

| **三姿换姿后疏忽未切回 Sighting** | **前一姿势中记录的多余弹全部作废（Void）**，靶面重置 | 口头指令 | Rule 6.10.4.c |
| **遮挡监视器屏幕 / 擅动打印机面板** | **严格禁止**：屏幕须全景可见；擅动打印机予以技术警告 | **黄牌 (警告)** | Rule 6.10.4.d/e |
| **全靶场故障中断恢复** | 排除后**加时 5 分钟**（提前 5 分钟广播通知并允许瞄准弹） | 广播公告 | Rule 6.10.9.1 |
| **单靶故障 5 分钟内无法修复** | 移至备用位 ➔ **加时 5 分钟** ＋ 允许发射不限量瞄准弹 | 记入 Form IR | Rule 6.10.9.2 |
| **EST 技术工程师越权裁判** | **严禁**：工程师仅提供数据与技术维护，无规则解释裁决权 | 报告 TD | Rule 6.10.1.b |
| **未经 RTS 仲裁许可执行 CLEAR LOG** | **严禁**：对底层日志的任何人工修改必须有 RTS 仲裁在场 | 严重违规 | Rule 6.10.8.3 |

## 十、ISSF 官方核准 EST 设备型号清单与认证管理规程 (Approved EST Systems)

> **三阶段认证机制（Phase 1–3 Testing）**：所有进入 ISSF 官方认证目录的电子计分靶，必须依次通过：
> 1. **第一阶段（Phase 1）**：权威实验室机械弹道枪严格精度测试（测量误差小于 0.05 毫米）；
> 2. **第二阶段（Phase 2）**：结合控制纸与现场运动员实弹环境风噪/温湿度干扰测试；
> 3. **第三阶段（Phase 3）**：在正式 ISSF 世界杯或世锦赛中由技术委员会执行现场全周期监督评估。

## 十一、EST 靶务与裁判工作流检查总表 (Checklist Table)

| 阶段 / 任务 | 核心技术操作规范 | 质量控制与红线要求 | 对应条款 |
| :--- | :--- | :--- | :--- |
| **赛前靶面核查** | 检查白色前板无弹孔，靶框旧痕涂黑 | 发现遗留弹痕必须在**开赛前彻底标记** | Rule 6.10.3.a/b |
| **控制纸更新** | 确认电机将控制纸推进至全白覆盖区 | 衬卡/衬靶在控制区外**无历史残留弹痕** | Rule 6.10.3.c/d |
| **三姿换姿监视** | 监视选手在显示屏上切换 Sighting | **未切回 Sighting 产生的多余弹一律作废** | Rule 6.10.4.c |
| **瞄准弹争议** | 移位复核，确认原靶正常处扣分 | **从第一组最低分中扣除 2 环罚分** | Rule 6.10.5.c |
| **比赛弹抗议** | 调取 LOG 日志并用光学规测控制纸 | **抗议驳回维持原判，处扣 2 环罚分** | Rule 6.10.7.d |

| **全场故障加时** | 记录中断发数，排除后**加时 5 分钟** | **提前 5 分钟广播通知**，允许发射瞄准弹 | Rule 6.10.9.1 |
| **日志安全控制** | 严禁私自点击 CLEAR LOG 清空数据 | 必须有 **RTS 仲裁现场监督并签字** | Rule 6.10.8.3 |
