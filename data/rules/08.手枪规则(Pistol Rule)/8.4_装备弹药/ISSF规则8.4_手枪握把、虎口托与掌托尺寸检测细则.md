# ISSF 手枪握把、虎口托与掌托尺寸检测细则 (Rule 8.4 & 8.12–8.13)

> **标准依据**：本细则依据国际射击运动联合会《手枪规则》（*ISSF Pistol Rules, Edition 2025 (Second Print 07/2026), Effective 1 July 2026*）第 8.4.1 节、第 8.12 节（手枪规格表）、第 8.13 节（构型图解）及《ISSF 装备控制指南》（*Equipment Control Guide*）整理编制，系统规范 10 米气手枪与 25 米手枪握把的几何构型、虎口后托长度、掌托角度、3D 打印握把合规性、手腕可见自由度、电子扳机外接禁令及 2026 周期器材检查法定操作规程。

---

## 一、2026 版握把与手枪构造【重大专项修订说明】

1. **3D 打印握把合规性与“防深度模塑”红线（Rule 8.4.1.1 b）** **【2026重大明确·3D打印握把与模塑界限】**：
   - **允许 3D 打印通用握把**：明确允许使用工程塑料、树脂或金属通过 3D 打印制造的握把（含网格、蜂窝及点阵减重结构），前提是整体刚性达标且符合几何尺寸限制；
   - **严禁原子灰/补土深度模塑**：**严禁针对运动员个人手型使用原子灰（Putty）、补土、环氧树脂等可塑材料进行“贴手深度模塑”**，杜绝握把边缘隆起包覆手指关节、手背或手侧而形成非法的“外骨骼式卡槽支撑”；
   - **握把主体刚性要求**：握把主体必须保持坚硬，**严禁使用海绵、软质硅胶、橡胶垫层等可压缩弹性材料**（防止运动员用力握枪时握把受压形变贴合包裹手部）。

2. **手腕可见自由与穿戴物绝对禁令（Rule 8.4.1.1 a）** **【2026执法严控·手腕完全悬空可见】**：
   - **肉眼直观可见**：正常据枪瞄准时，手腕关节（Wrist joint）四周必须与握把及枪身任何部件保持**清晰、肉眼可见的净空隙（Visibly Free）**；
   - **穿戴物清空**：持枪手和手臂上**严禁佩戴手表、手镯、智能手环、护腕、肌贴（Kinesio Taping）、医用胶布或绷带**，彻底杜绝借助穿戴物隐蔽固定、限制或支撑手腕。

3. **电子扳机外接通信绝对禁令与直接 DSQ（Rule 8.4.1.3 e）** **【2026新增·外接通信零容忍】**：
   - 电子扳机的所有电池、芯片和导线必须完全内置封闭；
   - 正式比赛及官方训练（PET）期间，手枪**严禁通过有线或无线（蓝牙/Wi-Fi）与任何外部电子设备（手机、平板、电脑等）连接**；
   - **违规罚则**：任何未经授权的外接通信行为，一经发现**直接出示红牌取消比赛资格（DSQ）**。

4. **枪管开孔与制退器严格区分（Rule 8.4.1.5 & Rule 8.12）**：
   - **10米气手枪**：允许使用枪管开孔、透气孔或枪口消跳补偿器；
   - **25米火药手枪**：**绝对严禁任何形式的枪管开孔、枪口制退器或后坐力补偿器**。

## 二、握把关键几何尺寸与角度限值对照表 (Rule 8.12 & Rule 8.13)

```
                            【手枪握把后部关键测量点图解】
                                    枪管轴线 (Barrel Axis)
                          ───────────────────────────────►
                                         │
                                         │ 虎口最深处 (Point C)
                                         ▼
                                       ┌───┐ ──► 尾部向上斜切角 ≥ 45°
                                       │ C │
                                  ┌────┴───┴─────┐
                                  │ 虎口后托长度 │ ──► 【10m ≤ 40mm / 25m ≤ 30mm】
                                  └──────────────┘
                                         │
                                         ▼ 握把主体 (Grip Body)
                                  ┌──────────────┐
                                  │              │
                                  │   掌托板     │ ──► 掌托外展角 ≥ 90°
                                  │  (Heel Rest) │ ──► 手腕侧末端切角 ≥ 30°
                                  └──────────────┘
```

| 检查项目 | 10米气手枪 (Rule 8.12) | 25米手枪 (Rule 8.12) | 2026 法定技术执行标准与几何要求 |
| :--- | :---: | :---: | :--- |
| **虎口后托长度上限**<br>*(自 C 点量至后托最远端)* | **≤ 40 mm** | **≤ 30 mm** | 超过即判不合格；严禁虎口上方过度向后延伸托垫手背。 |
| **掌托（Heel rest）外展角度** | **≥ 90°** | **≥ 90°** | 掌托与握把主体夹角不得小于直角（适用于前、后及两侧掌托）。 |
| **手腕侧掌托末端切角** | **≥ 30°** | **≥ 30°** | 掌托末端必须相对垂线向上斜切 ≥30°，严禁平直延伸贴近手腕。 |
| **握把尾部上扬斜切角** | **≥ 45°** | **≥ 45°** | 自 C 点向后，握把后尾部相对枪管轴线向上斜切 ≥45°。 |
| **侧向曲率 D（防环抱限制）** | 朝向枪管轴线向下，<br>**严禁上扬或平行** | 朝向枪管轴线向下，<br>**严禁上扬或平行** | 自最深处向后，曲率严禁向上包裹手侧，**严禁环抱手部**。 |
| **枪管轴线相对虎口位置** | — | **枪管轴线必须从<br>虎口上方通过** | 25米手枪严禁将枪管轴线沉入虎口水平线以下。 |
| **枪管开孔 / 补偿器** | **允许** 开孔枪管及附件 | **严禁** 制退器与开孔枪管 | 气手枪允许消跳开孔；25米火药枪严禁开孔制退。 |
| **弹壳收集器 (Case Catchers)** | — | **允许使用** | 安装后整枪仍须能自由放入 25 米标准测量盒内。 |

## 三、器材检查（EC）实操三步法与检验流线 (Rule 8.4.1 & Rule 8.12)

```
  【第 1 步：手腕自由度与穿戴核验】 ──► 据枪目测手腕空隙，确认无手表、手环、肌贴或绷带
               │
               ▼
  【第 2 步：专用量规几何角度检验】 ──► 测量虎口托长度 (≤40/30mm) 及掌托 90°/30°/45° 夹角
               │
               ▼
  【第 3 步：标准测量盒自由合盖测试】 ──► 整枪放入测量盒，平整合盖（严禁外力挤压使盒变形）
```

1. **第一步：据枪目测手腕自由度与手部穿戴（Visual Inspection）**
   - 运动员以正常射击姿势单手据枪；
   - 裁判从侧面和上方目测：手腕关节与握把四周是否有肉眼可见的净空隙（Visibly Free）；
   - 核查手掌与握把表面：严禁使用胶水、树脂、防滑喷雾（仅限干爽镁粉/滑石粉）；
   - 核查持枪手及手臂：严禁佩戴手表、手环、紧箍物或任何肌内效贴布（Kinesio Taping）。

2. **第二步：量规检定几何角度与虎口长度（Gauge Verification）**
   - 使用 ISSF 官方手枪专用量规（Pistol Gauge）：
     - 测量 C 点至后托末端距离（10米 ≤ 40mm，25米 ≤ 30mm）；
     - 校验掌托 90° 外展角、末端 30° 切角以及尾部 45° 上切角；
     - 检查握把侧向曲率 D，确保无向上环抱包裹手部侧面的非法支撑。

3. **第三步：标准测量盒合盖测试 (Box Test - Rule 8.12)**
   - **10米气手枪测量盒内部尺寸**：`420 mm × 200 mm × 50 mm`（制造公差：`+1.0 mm / -0.0 mm`）；
   - **25米手枪测量盒内部尺寸**：`300 mm × 150 mm × 50 mm`（制造公差：`+1.0 mm / -0.0 mm`）；
   - **合盖检验标准**：包含握把、弹匣、瞄具在内的整枪必须能**自由放入盒内，盒盖能平整完全闭合**；严禁任何外力按压、强行挤压或导致盒体产生形变。

## 四、手枪握把与尺寸违规判罚速查总表

| 违规行为 / 缺陷情形 | 赛前检查（自愿/初检）处置 | 赛中巡查 / 赛后强制抽检罚则 | 规则依据 |
| :--- | :--- | :--- | :--- |
| **握把接触手腕 / 手腕无可见空隙** | 判定不合格，责令现场打磨整改 | 赛后抽检发现直接判定 **DSQ** | Rule 8.4.1.1 a |
| **持枪手/手臂佩戴手表、手环、肌贴** | 责令立即摘除，否则禁止入场 | 赛中巡查发现责令摘除；拒改判 **DSQ** | Rule 8.4.1.1 a |
| **使用粘合喷雾、胶水或树脂涂抹** | 责令彻底清洗握把与双手 | 赛中/赛后发现直接判定 **DSQ** | Rule 8.4.1.1 b |
| **原子灰深度模塑环抱包裹手部** | 判定不合格，责令铲除违规模塑层 | 赛后抽检发现直接判定 **DSQ** | Rule 8.4.1.1 b |
| **虎口后托超长（>40mm / >30mm）** | 判定不合格，现场锯短/磨短整改 | 赛后抽检发现直接判定 **DSQ** | Rule 8.12 |
| **掌托角度不足 90° / 切角不足 30°** | 判定不合格，责令调整角度后复检 | 赛后抽检发现直接判定 **DSQ** | Rule 8.12 / 8.13 |
| **整枪无法完全放入测量盒平整合盖** | 判定不合格，禁止使用该枪参赛 | 赛后抽检发现直接判定 **DSQ** | Rule 8.12 |
| **25米火药手枪枪管开孔/加装制退器** | 判定不合格，严禁带入靶场 | 赛中/赛后抽检发现直接判 **DSQ** | Rule 8.4.1.5 |
| **电子扳机在赛中连接外部设备(蓝牙)**| — | 构成严重技术作弊，**直接出示红牌 DSQ** | Rule 8.4.1.3 e |
