# ISSF 步枪 Annex B/C：装备控制测量表与违规警告表（Edition 2018）

> **标准依据**：本文件依据 ISSF 步枪专项附件 *Annex B – Equipment Control Measurements Form* 与 *Annex C – Equipment Control Code Violation Warning Form (EQ)（Edition 2018）* 整理，规范步枪射击服/射击裤**分区刚度与厚度测量记录格式**及装备违规**警告（EQ）文书流程**。与 06 通用规则《装备控制检测表单与技术测试规程》中的 Form EC-R 检测流程配套使用。

---

## 一、Annex B：装备控制测量表（Measurements Form）

### 1. 表头信息

- 运动员姓名（Athlete's Name）、参赛号（Bib Number）、NOC 代码、ISSF ID；
- 检测日期（Date of Testing）、检测员姓名（Examiner Name）；
- **制造商（Manufacturer）与颜色（Color(s)）**：上衣、裤子分别登记。

### 2. 上衣测量分区（Jacket，外侧测量 measured from outside）

```
        ┌──────────────── 射击上衣（外侧示意）────────────────┐
        │   分区 A–F 为【区域】而非固定点位：                    │
        │   A：左下幅   B：前中下幅   C：前中幅                 │
        │   D：右前幅   E：右下幅（含口袋区） F：上背部         │
        │   ※ 标注 "indicates area not specific position"      │
        │   ※ 门襟扣眼线（Button hole line）单列                │
        └──────────────────────────────────────────────────────┘
```

| 分区 | 刚度（Stiffness） | 厚度（Thickness） |
| :---: | :---: | :---: |
| A / B / C / D / E / F | 逐区填写实测值 | 逐区填写实测值 |
| **上衣封条号（Jacket Seal No.）** | 单独登记 | — |

### 3. 射击裤测量分区（Trousers，内侧测量 measured from inside）

```
        ┌──────────────── 射击裤（内侧示意）────────────────┐
        │   A/B：腰头左右   C/D：胯部左右（裤前身须对应        │
        │   C、D 位置实测） E/F：左右裤腿                      │
        │   ※ 官方提示：The area in front of the trousers      │
        │     should be tested respective to positions C & D   │
        └──────────────────────────────────────────────────────┘
```

| 分区 | 刚度（Stiffness） | 厚度（Thickness） |
| :---: | :---: | :---: |
| A / B / C / D / E / F | 逐区填写实测值 | 逐区填写实测值 |
| **腰带宽度（Belt mm）** | — | 实测毫米数 |
| **裤子封条号（Trousers Seal No.）** | 单独登记 | — |

**测量要点**：分区字母标示"区域"而非具体点位；上衣自外侧测量，裤子自内侧测量；裤前身区域必须按 C、D 对应位置实测。

## 二、Annex C：装备控制违规警告表（Form EQ）

### 1. 表单要素

```
┌──────────────────────────────────────────────────────────────────────┐
│          EQUIPMENT CONTROL CODE VIOLATION WARNING — 【EQ】           │
├──────────────────────────────────────────────────────────────────────┤
│ 事件报告编号 (Incident Report Number): __________                     │
│   ※ 必须在靶场登记簿（Range Register）中留存记录                      │
│ 违规日期 (Date of Violation): __________  时间 (Time): __________     │
│ 运动员姓名 (Athlete's Name): __________                               │
│ 参赛号 (Bib Number): ________  国家/地区 (Nation): ________           │
├──────────────────────────────────────────────────────────────────────┤
│ 装备违规描述 (Description of Equipment Code Violation):               │
│   （多行填写）                                                        │
├──────────────────────────────────────────────────────────────────────┤
│ 要求整改措施 (Corrective Action Requested):                           │
│   （多行填写）                                                        │
├──────────────────────────────────────────────────────────────────────┤
│ 仲裁签名 (Signature of Jury Member) / 正楷姓名 (Printed Name) / 时间  │
└──────────────────────────────────────────────────────────────────────┘
```

### 2. 法定效力（IMPORTANT 条款）

> **收到装备违规警告（EQ Warning）的运动员，可于当日、当个项目继续使用该装备参赛。**

- EQ 警告是**书面警示 + 限期整改**文书，**不是即时禁用或 DSQ**；当场判 DSQ 仅适用于规则明文规定的赛后强制抽检不合格等情形（见 Rule 6.7.6、7.5 判罚体系）；
- 每份 EQ 警告**必须登记入靶场登记簿（Range Register）**，形成可追溯的违规档案，作为后续加重处理的依据。

---

## 三、两份表单的执法衔接

```
  Annex B 测量表（检测记录）                Annex C 警告表（EQ，违规处置）
  ────────────────────────                ────────────────────────────
  上衣 A–F / 裤子 A–F 分区刚度厚度    ──►   对发现的违规开具书面警告
  + 封条号 + 腰带宽度                        载明违规描述 + 整改要求
  合格 → 加封 ISSF 防伪封条                  当日当项可续用装备
  不合格（赛前）→ 整改复检                   记录入 Range Register 留档
```
