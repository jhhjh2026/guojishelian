# ISSF 步枪 Annex A：鞋底柔韧性测试操作指南（Edition 2018）

> **标准依据**：本指南依据 ISSF 步枪专项附件 *Annex A – Instructions for Conducting Shoe Sole Flexibility Tests Rifle (Edition 2018, Effective 1 January 2018)* 逐条整理，规定步枪射击鞋鞋底柔韧性测试台（Tester）的法定操作流程、定位基准、扭矩标准与记录要求。该装置亦可用于手枪鞋测试。

---

## 一、测试原理与合格线

1. **测试原理**：以 **15 N·m（牛顿·米）** 的设定扭矩弯折鞋底——该数值经测算为普通人正常行走、脚跟先于脚尖离地时弯折鞋靴所施加的平均力值；
2. **合格判定**：在 15 N·m 扭矩下，鞋底弯折角度**须 ≥ 22.5°**（软性鞋底通常可轻松达到 30° 以上）；数显角度计读数为准，测试台侧附标尺（刻度线对齐即 22.5°）为精度较低的备选读数方式；
3. **设计目的**：防止运动员借过硬鞋底获得非自然行走/站立支撑（如"企鹅式"行走）。

---

## 二、测试台组装与每日维护

```
  【组装流程】
  取出全部部件 ──► 用夹钳将测试台固定于水平平面（桌面为宜）
       ──► 装入手柄与带卡扣螺栓（第一根销插入孔位，手指辅助插入第二根销）
       ──► 装入两个垫圈与两个卡扣 ──► 测试台就绪

  【每日维护红线】
  每日使用结束必须旋转主轴将扭矩压力归零——严禁扭矩扳手带压过夜！
```

## 三、法定测试操作步骤（Operating Instructions 1–9）

| 步骤 | 操作要求 |
| :---: | :--- |
| **1** | 确认测试台夹持在**水平平面**上 |
| **2** | 核查扭矩扳手设定为 **15 N·m** |
| **3** | 将扭矩扳手**完全插入**测试台带数显计数器一侧的六角孔 |
| **4** | 开启数显计数器，按下三个黄色按钮中居中、带角度（°）标识的按钮 |
| **5** | 将鞋置于压杆下并夹紧——夹持装置保证压力一致（同一只鞋在不同夹持压力下会读出不同数值，必须统一） |
| **6** | 鞋头帽（toe cap）前伸量对准**绿色标记区**定位——多数鞋应以鞋面自然行走折痕（crease）对应绿色标记区，**与鞋码、宽度无关**，每只鞋定位须一致 |
| **7** | **缓慢**下压扭矩扳手——过快施压会产生虚假读数 |
| **8** | 逐鞋记录：制造商、型号、使用年限、颜色、男/女款、鞋底"折断"前达到的角度、鞋底厚度、有无内垫（硬质或软质） |
| **9** | **复检不得使用测试台**：改用手工弯折检查（不要求弯至 45°），仅确认鞋底仍具有一定柔韧性 |

## 四、折痕点定位基准（Crease Point Reference）

1. 每只鞋均有自然折痕点（crease point）：
   - **小号鞋**：折痕点约在鞋头帽 10 mm 前伸量之前 **9–10 cm** 处；
   - **大号鞋**：约在鞋头帽 10 mm 前伸量之前 **10–11 cm** 处；
2. 数显开启后直接读取角度（°）；使用侧标尺时，标尺刻线与台身刻线对齐即为 22.5°；
3. 插入扭矩扳手下压至发出"咔嗒（click）"声即达 15 N·m，此时读数判定。

## 五、与现行规则的衔接

1. 步枪射击鞋的通用规范（鞋底厚度、鞋帮高度、封条管理）见本目录《ISSF规则7.5_步枪射击鞋、射击手套与装备附件规范》及 Rule 7.5.7；本 Annex A 专规定**测试台法定操作流程**；
2. 手枪鞋测试（Rule 8.4.5，15 N·m / ≥22.5°）见 06 通用规则《装备控制检测表单与技术测试规程》，官方明示本装置**亦可用于手枪鞋测试**；
3. 测试仪器问题与协助请联系 ISSF 总部。
