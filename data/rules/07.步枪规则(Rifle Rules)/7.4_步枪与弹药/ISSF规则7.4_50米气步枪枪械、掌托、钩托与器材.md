# ISSF 50米步枪枪械与器材专项技术规范 (Rule 7.4.5)

> **标准依据**：本规则依据国际射击运动联合会《步枪规则》（*ISSF Rifle Rules, Edition 2025 (Second Print 07/2026), Effective 1 July 2026*）第 7.4.5 条（*50m Rifle*）、第 7.4.1 条（通用步枪标准）、第 7.4.6 条（弹药规则）及最新《ISSF 步枪器材检查指南》（*Rifle Equipment Control Guide*）编制，系统规范 50 米步枪（三姿与卧射）的枪支构型、8.0 kg 总重限制、钩式托底板（Hook Butt Plate）曲率边界、立姿掌托（Palm Rest）使用标准、严禁配重兼作两脚架新规、.22 LR 缘发弹药规范及器材检查技术红线。

## 一、核心数据与 50 米步枪关键参数速查

| :--- | :---: | :--- | :--- |

## 二、整枪重量与配重分布红线 (Rule 7.4.5.1)

```text
  【系统最末端】
         │
         │◄──────────────── 前护木配重前伸最大距离 ≤ 700 mm ────────────────►│
  ┌──────┴──────────────────────────────────────────────────────────────────┐
  │                           50米步枪枪机与前护木                          │
  └──────────────────┬──────────────────────────────────────┬───────────────┘
                     │                                      │
                     ▼                                      ▼
             【枪膛中心线向下垂距】                  【枪膛中心线向下垂距】
           前护木配重最低点 ≤ 90 mm                   立姿掌托最低点 ≤ 200 mm
```

1. **8.000 kg 整枪总重量上限**：
   - 男子与女子 50 米步枪整枪总重**均不得超过 8.000 kg**；
   - 称重范围包含：枪身本体、前后瞄准具、遮光板、枪管延长管、安装的全部配重块、手止（Hand Stop）以及**立姿所使用的掌托（Palm Rest）**；
   - *注：若决赛安装转播用瞄准轨迹追踪传感器（SCATT），传感器本体重量依法予以豁免，但连接夹具仍须计入总重。*
2. **前护木配重几何边界**：
   - 前护木配重块最低点距枪膛中心线垂距**不得超过 90 mm**；
   - 前护木配重向前延伸距系统后端（Action rear）**不得超过 700 mm**；
   - 枪管配重必须安装在距枪管中心线 **30 mm 半径之内**。
3. **【2026 核心禁令·严禁配重兼作两脚架】**：
   - 运动员在靶位放下步枪或转换姿势时，**枪托或前护木上的配重块严禁设计、改装或构造为充当两脚架（Bipod）支撑枪身独立站立**；
   - 枪身放置时必须使用组委会提供或自带的独立合规步枪支架。

## 三、钩式托底板 (Hook Butt Plate) 法定尺寸与构型限制 (Rule 7.4.5.1)

50 米自由步枪允许使用钩式托底板以增强立姿及跪姿的抵肩稳定性，但必须严格受控于以下几何红线：

```text
                                  ┌─── 顶部向后突起 ≤ 25 mm
                                  │
                              ┌───┴───┐
                              │       │
  抵肩最深点垂直基准线 ───────┼───┐   │ 托底板主体
                              │   │   │
                              │   └───┤
                              │       │
                              │       │
                              │       └───┐
                              │           │ 枪托钩 (Hook)
                              │◄── A ────►│
                              │           │
                              └───────────┘
               【A: 钩向后最大投影距离 ≤ 153 mm】
               【B: 钩沿外弧线展开总长度 ≤ 178 mm】
```

1. **向后最大投影距离（A）**：
   - 自托底板抵肩接触面最深凹陷点作垂直参考线，枪托钩向后延伸的最大水平直线距离（A）**不得超过 153 mm**。
2. **外表面总展开弧长（B）**：
   - 沿枪托钩弯曲外表面轨迹测量的总弧长（B）**不得超过 178 mm**。
3. **顶部突起限制**：
   - 托底板顶部向后延伸的凸起距离**不得超过 25 mm**。
4. **禁止构型**：
   - 枪托钩**严禁设计有任何向前延伸、侧向伸出或环形抱死腋下的附加副钩/凸起结构**。

## 四、掌托 (Palm Rest) 使用规范与姿势限制 (Rule 7.4.5.2)

1. **姿势限制：仅限立姿使用（Standing Position Only）**：
   - 掌托（俗称“蘑菇头”或托手块）**仅允许在 50 米步枪立姿比赛阶段安装使用**；
   - **卧姿与跪姿阶段严禁安装掌托**；在转换至卧姿或跪姿前，运动员必须将掌托完全拆除；
   - 10 米气步枪与 300 米标准步枪全时段严禁使用掌托。
2. **深度尺寸限制**：
   - 掌托的最低点距枪膛中心线的垂直距离**不得超过 200 mm**。
3. **人体工学塑形合规**：
   - 掌托本体**允许依据运动员手掌形状进行人体工学手指凹槽模塑或使用可调多节结构**。

## 五、手枪式握把、手止与枪带规范 (Rule 7.4.1.4 & 7.4.5.3)

1. **手枪式握把防搭靠与手腕解脱**：
   - 握把向侧方延伸不得超过 **60 mm**，深度不得超过 **160 mm**；
   - **严禁支持手腕**：握把构型严禁延伸至触及、支撑或包裹手背或手腕关节；
   - **防搭靠红线**：握把必须调整至**绝对不得搭靠、接触持枪手臂或枪带（Sling）**。
2. **手止（Hand Stop）与枪带连接**：
   - 允许在前护木导轨上安装手止，用于卧姿和跪姿连接射击枪带；
   - 手止最大厚度与宽度必须符合导轨安全界限，且必须牢固锁紧。

## 六、瞄准具、延长管与遮光板规范 (Rule 7.4.1.6)

1. **瞄具与透镜系统**：
   - 仅限使用机械式前后瞄准具（后照门 Diopter + 前准星罩 Globe sight）；
   - 前后瞄具内部**严禁安装任何具有放大成像功能的透镜系统**；
   - 视力矫正镜片仅允许安装在后照门外侧（严禁内置于照门内部）。
2. **枪管延长管与准星前沿**：
   - 允许安装枪管延长管（Tubes），但延长管必须为实心无孔结构（严禁排气制退孔）；
   - 前瞄准具（准星罩）**绝对不得向前超出外观枪口截面**。
3. **遮光板尺寸限制**：
   - 安装在后瞄具或枪身上的遮光板：最大纵深（A）**不得超过 30 mm**；非瞄准眼侧自照门中心向外延伸（B）**不得超过 100 mm**；瞄准眼一侧严禁安装遮光板。

## 七、5.6 mm (.22" LR) 缘发弹药规范 (Rule 7.4.6)

```text
  【50米步枪弹药检验标准】
         │
         ├─ 1. 口径规格 ──→ 5.6 mm (.22" LR 缘发式长步枪弹 / Rimfire)
         ├─ 2. 弹头材质 ──→ 必须完全由【纯铅 (Pure Lead) 或软质铅合金】制成
         ├─ 3. 禁用弹种 ──→ 严禁铜被甲弹、镀铜硬质弹、穿甲弹及高压实弹
         └─ 4. 装药安全 ──→ 符合 CIP / SAAMI 国际标准膛压
```

## 八、器材检查（Equipment Control）与三姿检验流程

```text
  【赛前器材检查 (Pre-Competition Control)】
   ├─ 称量整枪总重 (含掌托/瞄具/配重 ≤ 8.000 kg)
   ├─ 测量钩式托底板 (向后 ≤ 153mm / 外弧长 ≤ 178mm / 顶突 ≤ 25mm)
   ├─ 测量立姿掌托 (下延深度 ≤ 200 mm)
   ├─ 查验前护木配重 (深度 ≤ 90mm / 前伸 ≤ 700mm / 无两脚架功能)
   ├─ 检验握把 (无搭靠枪带/无手腕支撑) 与遮光板 (30×100mm)
   └─ 查验弹药规格 (5.6mm .22 LR 纯铅弹)
         │
         ▼
  【加贴 ISSF 官方防伪合规标签】──→ 准予进入正式比赛
         │
         ▼
  【比赛期间靶位监督】
   ├─ 检查卧姿/跪姿阶段是否已【彻底拆除掌托】(违规安装直接判罚)
   └─ 检查枪身放下时是否违规使用配重充当脚架
         │
         ▼
  【赛后随机抽检 (Post-Competition Check)】
   ├─ 抽检整枪总重 (≤ 8.000 kg)
   └─ 抽检未通过者 ──→ 【直接取消比赛成绩与资格 (DSQ)】
```
