# ISSF 300米标准步枪枪械与弹药专项技术规范 (Rule 7.4.3)

> **标准依据**：本规则依据国际射击运动联合会《步枪规则》（*ISSF Rifle Rules, Edition 2025 (Second Print 07/2026), Effective 1 July 2026*）第 7.4.3 条（*300m Standard Rifle*）、第 7.4.1–7.4.2 条（通用步枪标准）、第 7.4.6 条（弹药规则）及最新《ISSF 步枪器材检查指南》（*Rifle Equipment Control Guide*）编制，系统规范 300 米标准步枪的尺寸构型、1500g 扳机赛后即检机制、全姿势单枪与禁快拆限制、762mm 枪管限值、大口径中心发火弹药要求及器材检查执裁红线。

---

## 一、核心数据与 300 米标准步枪关键参数速查

### 300米标准步枪核心技术参数与红线速查表

| 检验项目 (Key Feature) | 官方尺寸上限 / 法定标准 | 测量基准 / 检验工具 | 违规判定与法律后果 |
| :--- | :---: | :--- | :--- |
| **最小扳机引力 (L)** | **≥ 1500 g (1.500 kg)** | 赛后竖直提拉 1500g 标准砝码（最多 3 次） | **未通过直接取消比赛资格 (DSQ)** |
| **枪管总长度 (O2)** | **≤ 762 mm (30 in)** | 枪管后端至外观枪口（含延长管） | 超出即器材检查不合格，禁止参赛 |
| **整枪最大总重量 (M)** | **≤ 5.500 kg** | 含瞄具、全套配件与配重（不含弹药） | 超重判定不合格；赛后抽检超重直接 DSQ |
| **三姿构型一致性** | **全姿势同枪且禁快拆** | 严禁使用快拆杆（Quick Release Fasteners） | 发现快拆或姿势间改动结构直接判违规 |
| **托底板总长与宽度 (H)** | **153 mm × 30 mm** | **【2026标准·153×30mm 矩形模板盒】** | 无法完全套入模板盒者判定器材不合格 |
| **托底板凹陷弯曲度 (G)** | **≤ 20 mm** | 托底板抵肩弧面最深处凹陷深度 | 超过 20mm 判定不合格 |
| **手枪式握把 (E/J2)** | **深 ≤ 160mm / 侧向 ≤ 60mm** | **允许通用 3D 网格握把；严禁用腻子个性化塑形** | 发现腻子/手模定制塑形者取消合规标识 |
| **前护木深度与宽度 (D/I)** | **深 ≤ 140mm / 宽 ≤ 60mm** | 自枪膛中心线起算；**表面必须平直无指槽** | 严禁人体工学模塑，严禁添加防滑砂纸 |
| **掌托 / 钩托底板** | **全时段绝对禁用 (Prohibited)** | 300m 标准步枪严禁安装掌托与钩托 | 违规安装直接判定不合格 |
| **适用弹药口径** | **最大 ≤ 8.0 mm 中心发火** | 仅限中心发火常规弹（如 6mm BR, 6.5×47 等） | **严禁穿甲弹、曳光弹与燃烧弹** |
| **防热浪带最大宽度** | **≤ 60 mm** | 枪管上方安装的导热/防视线晃动织带 | 超过 60mm 必须拆除或修剪 |

## 二、1500g 扳机引力赛后即检与裁决程序 (Rule 7.4.3.a)

300 米标准步枪采用极严苛的 **赛后立即重力提拉检验机制**，其执行程序与判罚标准如下：

```text
  【最后一组射击结束 (End of Match)】
         │
         ▼
  【靶场裁判员立即介入 (Immediate Post-Competition Check)】
  在射击位上令枪管保持垂直向上 (Barrel Held Vertically)
         │
         ▼
  【实施 1500g 标准砝码提拉测试】
   ├─ 第 1 次提拉 ──→ 砝码完全悬空离地且未击发 ──→ 【测试通过，成绩生效】
   │
   ├─ 若击发 (释放) ──→ 允许在裁判监督下重新上膛，进行【第 2 次提拉】
   │     ├─ 提起通过 ──→ 【测试通过】
   │     └─ 再次击发 ──→ 允许进行【第 3 次提拉 (最后机会)】
   │
   └─ 若连续 3 次提拉均无法提起 1500g 砝码 (释放击发)
         │
         ▼
  【法定终审判罚】
  依据 Rule 7.4.3.a【直接取消该运动员全部比赛成绩与资格 (DSQ)】
```

1. **重力检测规范**：
   - 检验必须在比赛结束后**立即在靶位上**或计分检录处进行；
   - 步枪必须处于待击发状态，枪管保持**完全竖直向上**，将 1500g 标准检验砝码挂于扳机中心接触点，平稳垂直向上提拉；
2. **3 次测试限额与 DSQ 红线**：
   - 运动员最多获得 **3 次连续提拉尝试机会**；
   - 只要有 1 次成功提起砝码且阻铁未释放，即视为合格；
   - 若 3 次尝试均击发（无法提起 1500g 重量），**裁判团无任何裁量宽限余地，必须直接判定取消资格（DSQ）**。

## 三、三姿全程单枪与禁快拆紧固件规范 (Rule 7.4.3.b)

为维护 300 米“标准步枪（Standard Rifle）”的本质属性，严禁在三姿（跪姿、卧姿、立姿）比赛转换中对枪支构型进行大幅重构：

```text
  【300m 标准步枪三姿全程】
         │
         ├─ 跪姿 (Kneeling) ──────┐
         ├─ 卧姿 (Prone) ─────────┼──→ 必须使用【同一支步枪】且【保持相同基本构型】
         └─ 立姿 (Standing) ──────┘
         │
         ▼
  【调节装置紧固件法定限制】
   ├─ 允许：使用内六角螺栓、固定螺丝等【需常规工具调节的紧固件】
   └─ 严禁：使用快拆手柄 (Quick Release Levers)、快拆卡扣或免工具手拧旋钮
```

1. **全姿势同枪原则**：
   - 运动员在跪姿、卧姿、立姿三种姿势中，**必须自始至终使用同一支步枪**；
   - 枪机（Action）、枪管（Barrel）与枪托主框架（Stock）在比赛全程严禁更换。
2. **严禁快拆紧固件（No Quick-Release Fasteners）**：
   - 枪托垫、贴腮板、托底板等调节机构上，**绝对禁止安装任何快拆扳手（Cam levers）、快速锁定卡榫或免工具快拆机构**；
   - 所有允许调整的部件必须使用标准螺栓（如内六角螺钉），必须借助外置工具方可松动调节，防止选手在靶位上快速大幅变更加重部件或几何尺寸。

## 四、枪管总长与枪口结构限制 (Rule 7.4.3.c & 7.4.1.5)

```text
  【枪膛与枪机后端】
         │
         │◄──────────────── 枪管总长度 O2 ≤ 762 mm (30 in) ────────────────►│
         │                                                                   │
  ┌──────┴─────────────────────────────────────────────┬─────────────────────┤ 外观枪口端面
  │                     步枪枪管 (Barrel)               │ 枪管延长管 (Extension)│
  └────────────────────────────────────────────────────┴─────────────────────┘
         ▲                                                                   ▲
         │                                                                   │
  【严禁开孔/穿孔 (No Ports)】                               【严禁制退器 (No Muzzle Brakes)】
```

1. **762 mm 枪管总长上限**：
   - 枪管本体连同固定安装的枪管延长管（Barrel Extension Tube），总长度**不得超过 762 mm（30 英寸）**；
   - 测量基准自枪膛弹室后端面起算，至延长管最前端的外观枪口截面为止。
2. **枪口制退与排气禁令**：
   - 枪管及延长管全长范围内**严禁有任何排气孔、泄气槽或减后坐开孔（No Vents/Ports）**；
   - **严禁使用任何形式的枪口制退器（Muzzle Brakes）或后坐补偿器（Compensators）**。

## 五、枪身几何尺寸与 3D 网格握把新规 (Rule 7.4.2 & Table 7.4.4.2)

> *注：尺寸 C、D、E、F、J1、J2、P、Q 均自枪膛中心线（Centre-line of bore）起算。*

### 1. 核心尺寸与技术边界对照表

| 标识 | 检验项目 (Key Dimensions) | 300m 标准步枪限值 | 技术规范与 2026 执行要点 |
| :---: | :--- | :---: | :--- |
| **A** | 准星罩最大长度 | **50 mm** | 最大限值 |
| **B** | 准星罩最大外径 | **25 mm** | 视线剖面呈正圆，外部无水平参考标记 |
| **C** | 准星中心至枪膛中心线高 | **80 mm** | 自枪膛中心线垂直起算最大限值 |
| **D** | 前护木最大深度 | **140 mm** | 表面必须平直，严禁人体工学手模与防滑砂纸 |
| **E** | 手枪式握把最大深度 | **160 mm** | **允许通用 3D 网格握把；严禁腻子塑形** |
| **F** | 枪托垫最大深度 | **140 mm** | 自枪膛中心线向下垂距（传统木托除外） |
| **G** | 托底板凹陷弯曲深度 | **20 mm** | 弧面最大深度限值 |
| **H** | 托底板总长度 | **153 mm** | **【2026标准·153×30mm 矩形模板盒检验法】** |
| **I** | 前护木最大宽度 | **60 mm** | 横向厚度最大限值 |
| **J1**| 贴腮板最大侧向延伸量 | **40 mm** | 距枪身中心线最大距离 |
| **J2**| 握把最大侧向延伸量 | **60 mm** | 距枪身中心线最大距离 |
| **K** | 托底板最大侧向偏移量 | **30 mm** | 距枪托垫中心线最大偏移量 |
| **M** | 整枪最大总重量 | **5.500 kg** | 含瞄具、附件与配重 |
| **N** | 准星向前延伸限制 | **严禁超出枪口** | 准星罩前沿严禁超出外观枪口截面 |
| **O2**| 枪管总长度 | **762 mm** | 含延长管在内的总长最大限值 |
| **P** | 后瞄具后方配重最大高度 | **60 mm** | 枪膛中心线上方最大限值 |
| **Q** | 前后瞄具间配重最大高度 | **30 mm** | 枪膛中心线上方最大限值 |

### 2. 托底板检验与禁用构型
- **153×30 mm 模板盒检验**：托底板宽度不得超过 30 mm，总长不得超过 153 mm，且必须能完整套入 153×30 mm 标准硬质模板盒中；
- **禁用部件红线**：
  - **严禁使用钩式托底板（Hook Butt Plate）**；
  - **严禁使用掌托（Palm Rest）**；
  - **严禁使用拇指孔（Thumb Hole）、拇指托（Thumb Rest）、脚跟托（Heel Rest）与枪身水平仪**。

## 六、中心发火弹药与防热浪带标准 (Rule 7.4.6 & 7.4.5.4)

1. **弹药规格要求（7.4.6）**：
   - 必须使用中心发火（Center-fire）常规弹药；
   - 弹头口径**最大不得超过 8.0 mm**（常见合规口径包括 6mm BR Norma, 6mm XC, 6.5×47mm Lapua, 6.5mm Creedmoor, 7.62×51mm / .308 Win 等）；
   - **安全与违禁弹种**：**严禁使用穿甲弹、钢芯穿透弹、燃烧弹、曳光弹或任何高压危险实验弹药**。
2. **防热浪带规范（7.4.5.4 Mirage Band）**：
   - 允许在枪管上方安装用于导流枪管高温热浪、防止瞄准视线晃动的防热浪带；
   - 防热浪带的最大宽度**不得超过 60 mm**。

## 七、器材检查（Equipment Control）检验与赛后复核流程

```text
  【赛前器材检查 (Pre-Competition Control)】
   ├─ 查验枪管总长 (≤ 762 mm) 与准星前沿 (不超枪口)
   ├─ 153×30mm 矩形模板盒套模检验托底板 (凹陷 ≤ 20mm)
   ├─ 查验紧固件 (确认无快拆杆)、握把 (无腻子手模) 与前护木 (无掌托)
   ├─ 查验防热浪带宽度 (≤ 60 mm) 与弹药口径 (≤ 8.0 mm)
   ├─ 称量整枪总重 (≤ 5.500 kg)
   └─ 赛前自愿测试 1500g 扳机引力
         │
         ▼
  【加贴 ISSF 官方防伪合规标签】──→ 准予参赛
         │
         ▼
  【赛后靶位强制即检 (Post-Competition Trigger Check)】
   ├─ 裁判竖直提拉 1500g 砝码测试 (最多 3 次)
   │     ├─ 提拉成功 ──→ 成绩正式确认
   │     └─ 连续 3 次提拉失败 (释放) ──→ 【直接判罚取消资格 (DSQ)】
   └─ 赛后随机抽查总重量 (≤ 5.500 kg)
```
