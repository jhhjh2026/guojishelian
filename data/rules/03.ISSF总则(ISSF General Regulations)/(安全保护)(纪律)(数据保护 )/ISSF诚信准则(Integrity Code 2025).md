# ISSF 诚信准则 2025（ISSF Integrity Code）

> **标准依据**：本文件依据 ISSF 官方独立文书 *ISSF Integrity Code 2025*（全文 27 条，A 引言 / B 一般义务 / C 防止操纵比赛 / D 执纪程序）逐条整理。**注意区分**：本准则 ≠ 总则附件 CE《道德准则（Code of Ethics）》——诚信准则是其升级版独立执法文书，设立独立的**诚信、道德与安全保护单元（the Unit）**统一管辖诚信、纪律、道德与安全保护（Safeguarding）案件；反兴奋剂事项不属本准则，由《ISSF 反兴奋剂规则》专属管辖（冲突时反兴奋剂规则优先）。

---

## 一、目的、适用范围与关键定义（A. Articles 1–2）

1. **适用对象（Covered Person, 1.2）**：ISSF 及会员协会各级官员与候选人、持 ISSF ID 运动员、各委员会成员与雇员、教练/队医/经纪人、赛事组织人员（技术代表、仲裁、裁判、志愿者）、申办城市及任何书面同意受约束者；
2. **立法目的（2）**：确立诚信标准、保护运动员健康安全、禁止任何损害公众对射击比赛完整性及**结果不确定性**信心的行为，并建立有效执纪与制裁机制；
3. **与其他规范关系**：违反《安全保护条例》即构成违反本准则；本准则是对国家刑法、枪支管理法、劳动法及其他 ISSF 规则的**补充而非替代**；《ISSF 纪律条例》保留适用；员工案件 ISSF 可径依合同追责；
4. **溯及力（2）**：程序条款溯及既往；实体条款不溯及既往，除非较旧《道德准则》对当事人更有利。

## 二、一般义务（B. Articles 3–10）

| 条款 | 义务 | 核心红线 |
| :---: | :--- | :--- |
| **3** | 良好行为义务 | 诚实、公平、公正；不得歧视（种族、性别、宗教、性取向等）；不得攻击/暴力/不敬（含对兴奋剂检查官）；不得干扰赛场；违反 Safeguarding 即违反本准则 |
| **4** | 报告与协作义务 | **立即向 Unit 报告**任何操纵比赛的接触/邀请及可疑线索；持续报告义务；全力配合调查（含按 Demand 提交资料）；**阻挠调查、销毁证据、报复证人本身即构成违规** |
| **5** | 保密义务 | 不得向第三方披露 ISSF 机密信息；**保密义务永久存续**（离职后仍有效） |
| **6** | 利益冲突回避 | 对 ISSF 负"不可分割的忠诚"；任职时提交利益申报并持续更新；会议中遇冲突须申报、**回避讨论与表决**；机构性冲突（与所属协会利益冲突）**不可豁免** |
| **7** | 反伪造与资金滥用 | 严禁伪造文件、虚报成绩/国籍/出生日期；严禁行贿、挪用资金；报销仅限合理实际开支 |
| **8** | 礼品与招待 | **严禁**秘密收受、或足以造成利益冲突/影响公正的礼品招待；**名义价值内**的礼节性礼品可接受，**超名义价值须向诚信官申报**，未获批准须退回 |
| **9** | 申办纪律 | 申办城市不得与对手串通、不得拉拢 ISSF 赞助商站台、**不得为执委/理事报销差旅住宿**（中标前）；官员对申办保持中立 |
| **10** | 选举纪律 | 候选人不得作约束当选后决策的承诺、不得结盟操纵投票、不得动用 ISSF/政府/奥委会资源助选；投票代表不得收受候选人礼品招待 |

## 三、防止操纵射击比赛（C. Articles 11–12）【最严红线】

1. **总体承接（11.1）**：全体 Covered Person 受《奥林匹克运动防止操纵比赛准则》约束；
2. **四类操纵违规（11.2）**：
   - **a) 博彩禁令**：本人及**关联方（配偶/父母/子女等近亲）**严禁对任何射击赛事投注；运动员参加综合运动会期间（如奥运会）**严禁对该运动会任何项目投注**（含非射击项目）；
   - **b) 操纵比赛**：故意安排、作为或不作为以不正当地改变比赛结果或进程、消除结果不可预测性以谋取不正当利益——含**整体假赛（match-fixing）与局部操纵（spot-fixing）**；
   - **c) 涉操纵利益输送**：索取/收受贿赂操纵比赛；为利益不尽全力比赛；收受可能损害公众信心的利益（不论是否实际交付）；
   - **d) 内幕信息**：利用内幕信息投注或操纵；向他人泄露内幕信息；为提供内幕信息收送利益；
3. **与博彩机构关系（12）**：严禁 Covered Person 与博彩机构发生任何含金钱/利益给付的商业关系；母公司下设博彩子公司的雇佣关系须证明无直接关联、无利益输送方可豁免；**关联方控股或实际运营博彩机构的，须向诚信官申报获批**，否则视为违规。

## 四、执纪机构：诚信、道德与安全保护单元（D. Articles 13–15）

```
              【ISSF Integrity, Ethics and Safeguarding Unit（"the Unit"）】
   ┌───────────────────────────────────────────────────────────────────────┐
   │ ① 诚信道德与安全保护理事会（≤3人，ISSF理事会任命）—— 监督、预算、任免   │
   │ ② ISSF 诚信官（Integrity Officer）—— 举报热线、立案初查（prima facie） │
   │ ③ 调查机构（Investigatory Body）—— 个案任命、独立调查、提交调查报告    │
   │ ④ 裁决机构（Adjudicatory Body，5人）—— 组独任或三人裁决庭审理定罚     │
   └───────────────────────────────────────────────────────────────────────┘
```

1. **管辖分工（14.2.2）**：Unit 仅管辖 **ISSF 赛事及 ISSF 专属事务**，不管辖会员协会国内赛事（会员协会不作为时 Unit 可介入）；本准则与会员协会诚信规范冲突时**本准则优先**；决定对全体会员协会自动生效、相互承认；
2. **腐败监测（15）**：监测异常投注模式、运营举报热线、与执法/司法机构及其他体育组织交换情报、开展教育项目。

## 五、执纪程序（Articles 16–23）

1. **举报（16）**：任何人可经官网渠道举报，**允许匿名**；举报人身份仅在调查必需且本人书面同意时方可披露；
2. **立案初查（17）**：诚信官评估表面管辖权与成案可能；不成案的决定**不可上诉**；被调查人获通知并有权书面陈述，**拒绝接受访谈即构成违规**；
3. **临时措施（18）**：当人员安全或公众信心面临重大风险时可先行临时禁赛等措施，**临时措施决定不可上诉**，违反临时措施构成新违规；主动配合的临时停赛期**可折抵**正式禁赛期；
4. **调查（19）**：调查机构可调取文件、传唤访谈（可由律师陪同）；**毁损、隐匿证据构成独立违规**；调查报告作为事实认定直接进入案卷；认定无需继续调查的，案件终结并解除临时措施；
5. **和解出价（20）**：理事会可向被调查人提出"建议后果（Proposed Consequences）"替代听证：一般案件被调查人**10 个工作日**内答复，**逾期不答视为默认接受**；Safeguarding 案件须先经指控方 7 个工作日同意，被调查人再有 7 个工作日；双方接受后放弃上诉权，20 个工作日内出具终局决定；
6. **举证与裁量（22）**：除 Safeguarding 案件（指控方举证）外由 Unit 举证；证明标准统一为**优势证据（balance of probabilities）**；适用**严格责任**——不论故意、鲁莽或过失均处罚；拒不配合可被作出**不利推定**；
7. **决定（23）**：裁决以多数作出、不得弃权；决定经电子邮件送达即生效；**未成年人涉案决定一律不得公开**（全体同意除外且须去识别化）。

## 六、制裁与加重/减轻情节（Article 24）

1. **制裁种类（24.1, a–n）**：警告、察看期、训诫、**罚款**、退赔、暂停特定职务、免职、剥夺特权、禁止接触令、**取消积分/奥运席位/主办权**、强制教育课程、收回 ISSF 奖项、**取消资格期（ineligibility）**及其他必要措施；
2. **加重情节（24.3）**：职位高/资历深、有前科、多次或多条违规、获取重大利益、影响比赛进程结果、团伙作案且涉胁迫、调查中欺骗阻挠或报复证人、拒不悔改；
3. **减轻情节（24.4）**：年轻无经验或被资历深者利用、无前科、未获利益、未影响比赛、**及时承认**、配合调查、**提供实质协助（Substantial Assistance）**、悔罪、过失而非故意；
4. **执行细则（24.5–24.11）**：数罪以最重者为基准加重；禁赛期自作出之日起算并折抵已服临时停赛期；可附条件暂缓执行；**禁赛期内不得参加任何赛事/活动/任职**，违反则禁赛期重新起算并立即取消相关赛事资格；可责令完成反骚扰教育康复课程。

---

## 七、上诉、承认与时效（Articles 25–27）

1. **上诉（25）**：仅可上诉至 **CAS**，须自收到书面决定电邮之日起 **21 个自然日**内提出；**上诉不中止执行**；CAS 程序以英语进行，实体适用本准则并补充适用德国法；
2. **承认与执行（26）**：依本准则作出的决定（含 CAS 裁决）全球适用，ISSF 及全体会员协会须无条件承认执行；
3. **时效（27）**：追诉时效**自违规行为发生之日起 10 年**；指控方为未成年人的，**自其成年之日起 7 年**。
