# ISSF 总则附件 G — 组委会办赛通用程序指南 (Annex G)

> **标准依据**：本文件依据 *ISSF Rule Book (Edition 2025 (Second Print 07/2026), Effective 1 July 2026)* 第 3 章《总则》（*General Regulations*）第 3.13.3.3 条法定附件 G（*Annex G — General Procedures for Organizing Committees*）整理编制，系统规范 ISSF 官方锦标赛组委会（LOC）的法律设立、倒排里程碑控制、枪支弹药口岸通关、主枪械库（Armory）最高安保、靶场硬件光照几何参数验收及赛时技术运行规程。

---

## 一、办赛法定周期与关键里程碑倒排表（Annex G.1）

组委会必须自签署《主办联合会协议》（HFA）起，严格依据以下法定时间节点推进筹备：

```
┌───────────────┬─────────────────────────────────────────────────────────────────────────────┐
│ 倒排时间节点  │                           组委会必须履行的法定筹备任务                      │
├───────────────┼─────────────────────────────────────────────────────────────────────────────┤
│ T - 24 个月   │ 签署正式 HFA 协议，向 ISSF 缴纳办赛保证金（世锦赛€10万 / 世界杯€5万）        │
│ T - 12 个月   │ 技术代表 (TD) 实施首次现场实地考察，全面复核靶位几何间距与 EST 电子靶网络   │
│ T - 8 个月    │ 提交初步竞赛日程表（Preliminary Programme），确定酒店、班车及餐饮接待标准   │
│ T - 6 个月    │ 发布官方《最终竞赛日程》与《赛事通用信息通函（General Information）》，开放报名│
│ T - 60 天     │ 启动枪支弹药临时入境报备，向所有参赛国无偿核发《海关临时枪弹入境许可证》    │
│ T - 30 天     │ 最终报名截止（Final Entry Deadline）；锁定官方酒店房间与接送机车辆排班表    │
│ T - 3 天      │ TD 与陪审团完成靶场封场验收（光照度/防弹挡板/EST服务器），召开官方技术会议  │
└───────────────┴─────────────────────────────────────────────────────────────────────────────┘
```

## 二、枪支弹药通关、口岸押运与主枪械库安保（Annex G.2）

### 1. 海关通关绿色通道与武装押运
* **免费/平价入境批文**：组委会必须协调所在国内政部、海关总署与警务部门，在赛前 60 天开启线上办证系统，为所有合规报名的运动员及随队官员办理免税或平价的《枪弹临时入境许可证》；
* **口岸押运交接**：在官方入境国际机场设立“枪弹查验特设专用窗口”，边防海关核验枪号无误后，**由警务/专业武装押运安保团队统一将枪弹箱直运靶场主枪械库**，严禁运动员私自携带枪弹搭乘公共交通或进驻非官方酒店。

### 2. 主枪械库（Main Armory）最高安全硬件规范 **【2026安保红线】**

```
                       ┌── [ 24 小时武装安保值守 + 防爆装甲门 ]
                       ├── [ 360° 无死角高清 CCTV 监控 (录像加密留存 ≥ 90 天) ]
[ 主枪械库最高安保标准 ] ──┼── [ 双人双锁 (Dual-control Card/Key) 电子核验出入库制 ]
                       ├── [ 步手枪枪柜 / 飞碟枪架分类物理隔离锁死 ]
                       └── [ 独立恒温恒湿防爆弹药储存专用隔离间 ]
```

## 三、靶场技术参数、光照度与 EST 靶机验收（Annex G.3）

组委会在技术代表（TD）实施封场验收前，必须保证场地完全满足通用技术规则第 6.4 条要求：

```
┌──────────────────┬──────────────────────────┬──────────────────────────┬────────────────────┐
│     靶场类别     │     资格赛靶面光照度     │     决赛馆靶面光照度     │  射手席位光照度    │
├──────────────────┼──────────────────────────┼──────────────────────────┼────────────────────┤
│ 10米气枪靶场     │ ≥ 1500 Lux (均匀度≥0.85) │ ≥ 2000 Lux (可调光系统)  │ ≥ 1000 Lux (无阴影)│
│ 25米手枪靶场     │ ≥ 1500 Lux (全靶面均匀)  │ ≥ 2000 Lux               │ ≥ 1000 Lux         │
│ 50米步枪靶场     │ ≥ 1500 Lux (抗反光处理)  │ ≥ 2000 Lux               │ ≥ 1000 Lux         │
│ 飞碟抛靶场 (Trap)│ 自然采光，背景纯净无杂色 │ 辅以决赛夜间专业防眩照明 │ 射击席开阔无反光   │
└──────────────────┴──────────────────────────┴──────────────────────────┴────────────────────┘
```

* **EST 电子打分靶网络冗余**：
  - 靶机数据传输必须具备**主网（Main Cable LAN）与备用冗余信道（Backup Channel）**双物理链路；
  - 靶位主控服务器必须配备工业级不断电 UPS 电源，保证在主电网突发断电后能够**持续供电运行至少 四十五（45）分钟**，杜绝数据丢发。

## 四、核心功能区与服务保障中心配置（Annex G.4）

1. **注册与证件制作中心（Accreditation Center）**：
   - 设立于主靶场入口处，配置证件制卡机与防伪芯片读写器，负责核验参赛代表团护照、保险单及免责声明。
2. **装备检查中心（Equipment Control）**：
   - 配备经标定的专业检测仪器（皮服厚度规、硬度探头、扳机引力砝码、鞋底弯曲度量规及箱规）；
   - 设立官方初检区与加急复检区（**初检不合格装备复检每次加收 €20.00 欧元**）。
3. **武器检修工坊（Official Gunsmith）**：
   - 组委会必须在靶场安全区设立免费向所有选手开放的官方武器检修车间，常驻专业枪匠并储备压缩空气/二氧化碳合规充气台。
