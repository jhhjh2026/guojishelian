# ISSF 总则附件 R — 世界纪录认定与核准规程 (Annex R)

> **标准依据**：本文件依据 *ISSF Rule Book (Edition 2025 (Second Print 07/2026), Effective 1 July 2026)* 第 3 章《总则》（*General Regulations*）第 3.13.3.6 条法定附件 R（*Annex R — Procedures for Recognition of World Records*）及《通用技术规则》第 6.15 条（*World Records*）整理编制，系统规范世界纪录（WR/EWR）、资格赛世界纪录（QWR）、决赛世界纪录（FWR）及青年世界纪录（WRJ/QWRJ）的法定认定门槛、EST 电子靶原始数据核验、即时器材复检、反兴奋剂药检前置与正式证书核发流程。

---

## 一、世界纪录分类与法定术语定义（Annex R.1 – R.2）

1. **官方世界纪录体系分类**：
   - **WR（World Record）/ QWR（Qualification World Record）**：资格赛世界纪录（或无独立决赛项目之总成绩纪录）；
   - **FWR（Finals World Record）**：依据最新奥运/世锦赛 8 人制（步手枪）或飞碟决赛赛制创造的单项决赛世界纪录；
   - **WRJ / QWRJ / FWRJ**：青年世界纪录（仅限在满足青年组年龄标准的正式比赛中由青年射手创造）；
   - **EWR / EFWR（Equaled World Record）**：平世界纪录（分值与现有世界纪录完全相同）。

---

## 二、世界纪录成立之法定前置条件（Annex R.3）

一项射击成绩被正式认定为官方世界纪录，必须**同时且严格满足以下全部前置要素**：

```
┌─────────────────┬─────────────────────────────────────────────────────────────┐
│    法定要素     │                      强制合规技术指标                       │
├─────────────────┼─────────────────────────────────────────────────────────────┤
│ 1. 赛事级别门槛 │ 夏季奥运会、世界锦标赛、ISSF世界杯、洲际顶级锦标赛（具TD派驻）│
│ 2. 参赛国数门槛 │ 该小项必须有来自 ≥ 3 个不同国家/地区会员联合会的合规选手参赛  │
│ 3. 靶机认证门槛 │ 必须全程使用经 ISSF 官方认证且处于有效校验期的电子打分靶(EST)│
│ 4. 靶场几何标准 │ 靶心高度、靶距误差在通用技术规则 6.4 允许的 ±2mm/±25mm 范围内 │
│ 5. 即时器材复检 │ 赛后 15 分钟内完成射击服厚度/刚度、扳机引力及枪械全项强制复检 │
│ 6. 兴奋剂强制检 │ 创纪录选手必须在赛后 24 小时内完成 WADA 认证尿样与血样采集  │
└─────────────────┴─────────────────────────────────────────────────────────────┘
```

## 三、EST 电子靶数据核验与底层数据锁定（Annex R.4）

1. **原始传感器日志锁定（Raw Sensor Log Homologation）**：
   - 打出破纪录成绩后，成绩与计时陪审团（RTS Jury）及技术代表（TD）必须立即提取主控计算机与备用服务器中的底层声学/光学原始脉冲文件；
   - 核验各发弹着点 X/Y 坐标精确值与分段发射时间戳，确认系统不存在由于外部震动、跳帧或电磁干扰导致的虚拟打分。
2. **靶纸卷带与对发核对（Witness Strip Verification）**：
   - 步枪/手枪 10m/25m/50m 项目，必须当场由器材仲裁员封存 EST 靶机后的黑色靶纸见证卷带（Witness Paper Strip），核对弹孔物理穿透痕迹与电子读数完全吻合。

---

## 四、强制器材复检与反兴奋剂药检规程（Annex R.5）

1. **即时器材复检（Immediate Post-competition Equipment Control）** **【一票否决】**：
   - 创纪录选手在离开靶位后，必须在裁判陪同下立即进入器材检查室进行顶格复检：
     - **步枪皮服**：厚度（≤ 2.5mm）、刚度（探头下沉量 ≥ 3.0mm）、鞋底 22.5° 弯曲度；
     - **手枪**：扳机引力（10m气手枪 ≥ 500g；25m速射 ≥ 1000g；女子手枪 ≥ 1000g）、尺寸盒适配性；
     - **飞碟**：枪托下沉量标志带、铅弹装药量（≤ 24.5g）；
   - **复检不合格后果**：任何一项器材指标超标，**当场取消成绩（DSQ），世界纪录直接不予认定**。
2. **反兴奋剂强制检测（Mandatory Doping Control）**：
   - 创纪录运动员必须在赛后通知下达 **1 小时内** 抵达兴奋剂检查站，完成符合 WADA 标准的尿样及血样检测；
   - 若药检结果呈阳性反应，世界纪录自动作废，并移交纪律委员会处以禁赛与除名。

---

## 五、核准签发与官方证书登记（Annex R.6）

1. **四方联合签署报告（Ratification Protocol）**：
   - 赛事技术代表（TD）、分项总裁判长（CRO）、RTS 仲裁团主席与兴奋剂检查官必须在赛后 24 小时内联合签署《ISSF 世界纪录官方申报核准表》（Form WR-1）。
2. **官方公报与终身存证**：
   - ISSF 秘书处在收到完整技术核验包及药检阴性报告之日起 **十五（15）个工作日内** 完成终审复核；
   - 由 ISSF 主席与秘书长联合签发正式《世界纪录认定证书》，并在 ISSF 官方网站及全球数据库中更新公报。
