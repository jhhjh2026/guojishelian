# ISSF 总则附件 A — 公共事务与官方礼宾指南 (Annex A)

> **标准依据**：本文件依据 *ISSF Rule Book (Edition 2025 (Second Print 07/2026), Effective 1 July 2026)* 第 3 章《总则》（*General Regulations*）第 3.13.3.11 条法定附件 A（*Annex A — Guidelines for Public Affairs Activities*）整理编制，系统规范 ISSF 在全球射击运动推广、国际奥委会（IOC）及政府间组织关系协调、赛事官方礼宾规格（Protocol）、贵宾座次流线、危机公关响应及绿色靶场环保公共事务处置标准。

---

## 一、公共事务宗旨与治理架构（Annex A.1 – A.2）

1. **核心宗旨（Annex A.1）**：维护全球射击运动的崇高国际形象，强化与国际奥委会（IOC）、国家奥委会协会（ANOC）、国际单项体育联合会协会（ASOIF）以及举办国政府部门的战略协作，推动射击运动在法治化、绿色环保化及社会包容度维度的可持续发展。
2. **主管机构（Annex A.2）**：ISSF 公共事务与公关委员会（Public Affairs Committee）在主席团指导下，统筹全组织对外新闻发布、国际礼宾准则执行、社区环境保护宣导及重大突发事件危机公关。

---

## 二、官方礼宾体系与贵宾（VIP / VVIP）接待规范（Annex A.3）

### 1. 贵宾坐席与主宾席（Presidential Box）排位法定序列
在所有官方仪式、世锦赛及世界杯决赛中，贵宾主宾席（VIP Lounge / Tribune）必须严格按以下国际外交与体育礼宾层级排定座次：

```
                    ┌── [ 1. 举办国国家元首 / 政府首脑 / 王室成员 ]
                    ├── [ 2. 国际奥委会 (IOC) 主席或其正式指派特使 ]
                    ├── [ 3. 国际射击运动联合会 (ISSF) 主席 ]
[ 官方主宾席座次序列 ] ──┼── [ 4. 举办国国家奥委会 (NOC) 主席 / 体育部长 ]
                    ├── [ 5. ISSF 秘书长、第一副主席及执行委员会委员 ]
                    ├── [ 6. 国际单项体育组织 (ASOIF/GAISF) 官方代表 ]
                    └── [ 7. 主办城市市长 / 组委会 (LOC) 主席 ]
```

### 2. 贵宾动线与安保隔离
* **独立贵宾流线（VIP Dedicated Route）**：主场馆必须设立完全物理隔离的贵宾专用抵离落客区、独立安检通道及专属电梯/通道，严禁与运动员竞赛流线或媒体混采区发生交叉重叠；
* **证件管控**：主宾席实行专属“VVIP / VIP”全通证件查验，配备专业外事礼仪人员与专属双语安保梯队。

## 三、绿色环保、防铅与社区关系公关（Annex A.4）

1. **靶场环境合规通报（Environmental Communication）**：
   - 组委会与国家协会必须联合当地环保监管机构，建立常态化水土铅含量监测与噪音控制公报制度；
   - 飞碟靶场必须主动向周边社区公示无毒降解靶（Eco-friendly Targets）使用率与铅丸回收处理认证报告。
2. **社区无障碍与青年开放日（Community Engagement）**：
   - 赛事举办期间必须设立“大众射击与安全用枪科普体验区”，向驻地学校与社区开放激光/光电射击安全体验，化解公众对射击运动的安全顾虑。

---

## 四、官方新闻发布与突发事件危机公关响应（Annex A.5）

1. **唯一官方发言人制度（Designated Spokesperson）**：
   - 凡涉及赛事重大技术事故、靶场安全事件、涉兴奋剂阳性指控或纪律处分，**唯一合法信息发布渠道为 ISSF 主席、秘书长或正式授权的新闻官（Media Officer）**；
   - 任何裁判员、技术代表或组委会工作人员未经书面授权，严禁以个人名义或通过社交媒体向外部发表定性言论。
2. **黄金 2 小时危机响应机制（Crisis Protocol）** **【2026红线规范】**：
   - 一旦发生涉及人身伤亡、器材严重故障或涉嫌操纵比赛的重大舆情，危机公关专责组必须在 **两（2）小时内** 完成内部核实并起草第一份事实通报（Holding Statement）；
   - 通报必须恪守客观、透明与法治原则，杜绝信息瞒报或推诿推卸。
