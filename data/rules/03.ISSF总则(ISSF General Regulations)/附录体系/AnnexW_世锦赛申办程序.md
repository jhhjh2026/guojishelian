# ISSF 总则附件 W — 世界锦标赛与世界杯申办程序 (Annex W)

> **标准依据**：本文件依据 *ISSF Rule Book (Edition 2025 (Second Print 07/2026), Effective 1 July 2026)* 第 3 章《总则》（*General Regulations*）第 3.13.3.4 条法定附件 W（*Annex W — Application Procedures for World Championships and World Cups*）及《ISSF 重大赛事申办与主办权分配规程》整理编制，系统规范世界射击锦标赛（WCH）、青年世界锦标赛（WCH Junior）、ISSF 世界杯分站赛（World Cups）及世界杯总决赛（WCF）的申办主体准入、倒排申报周期、政府法定担保函、财务履约保证金、场地技术验收、执委会/理事会遴选表决及违约制裁规程。

---

## 一、申办主体准入与申办赛事层级分类（Annex W.1 – W.2）

1. **申办主体法定资质（Eligible Bidders）**：
   - 申办主体必须为**具备良好信誉且处于正常会员权利状态的 ISSF 正式国家/地区会员联合会（Member Federation）**；
   - 处于欠费、暂停会员资格或正接受纪律委员会严重违纪调查的联合会，**一律剥夺申办资格**。
2. **申办赛事层级划分**：
   - **Level 1（特级赛事）**：世界射击锦标赛（全项目 / 单项世锦赛）、青年世界射击锦标赛；
   - **Level 2（核心赛事）**：ISSF 世界杯分站赛（步枪/手枪/飞碟）、奥运资格选拔大奖赛；
   - **Level 3（精英赛事）**：ISSF 世界杯总决赛（World Cup Final）、各分项洲际资格赛。

---

## 二、申办倒排时间表与法定申报材料（Annex W.3）

申办协会必须严格按以下法定周期向 ISSF 慕尼黑总部提交申办档案：

```
[ T - 4 年 (世锦赛) / T - 2 年 (世界杯) ]: 提交正式《申办意向书》与缴纳官方申办规费
                                                    │
                                ┌───────────────────┘
                                ▼
[ T - 3 年 / T - 18 个月 ]: 递交完整《申办标书全卷》(Bid Dossier) + 五项政府法定担保函
                                │
                                ▼
[ T - 30 个月 / T - 12 个月 ]: ISSF 技术代表团现场实地考察评估 ➔ 签署 HFA 协议并缴纳履约保证金
                                │
                                ▼
[ 执委会审议 / 理事会差额投票 ]: 官方正式宣布赛事主办权归属并签发授权证书
```

### 必须随标书提交的《五大政府法定保证函》 **【一票否决红线】**
1. **无障碍签证保证函（Visa Guarantee Letter）**：举办国政府（外交部/内政部）承诺无歧视向所有合规报名的 ISSF 会员国代表团核发入境签证；
2. **枪支弹药免费/平价临时入境批文（Gun Import Permit Guarantee）**：保障参赛枪支弹药便捷免税清关与专业口岸押运；
3. **海关免税与器材通关保证（Customs Clearance Guarantee）**：对赛事专用电子打分靶（EST）、转播设备及参赛装备免征临时进口关税；
4. **最高安全保卫承诺函（Security & Safety Guarantee）**：国家警务与安保部门承诺提供靶场、官方驻地及主枪械库（Armory）全天候武装安保；
5. **财务履约反担保函（Financial Guarantee）**：主办城市政府或国家体育总局承诺对赛事运营亏损与不可抗力承担兜底连带责任。

## 三、办赛财务保证金与规费存退标准（Annex W.4）

申办与承办协会必须严格履行以下财务存退与缴纳义务：

```
┌──────────────────┬──────────────────┬──────────────────────────┬──────────────────────────┐
│     赛事级别     │   申办初审规费   │    法定办赛履约保证金    │     特许权费 (Royalty)   │
├──────────────────┼──────────────────┼──────────────────────────┼──────────────────────────┤
│ 世界锦标赛 (WCH) │ € 5,000 欧元     │ **€ 100,000 欧元** (现金/保函)│ 依商业合同单独核算       │
│ 青年世锦赛 (WCHJ)│ € 3,000 欧元     │ **€ 50,000 欧元**        │ 享受青年发展减免扶持     │
│ 世界杯分站赛 (WC)│ € 2,500 欧元     │ **€ 50,000 欧元**        │ 包含官方 RTS 计分系统授权│
│ 世界杯总决赛(WCF)│ € 2,000 欧元     │ **€ 30,000 欧元**        │ 包含总决赛奖金池专项托管 │
└──────────────────┴──────────────────┴──────────────────────────┴──────────────────────────┘
```

* **保证金存退机制**：
  - 赛事圆满闭幕、经技术代表（TD）出具技术决算评估报告且组委会全额结清应付账款后 **三十（30）个工作日内，保证金全额无息退还**；
  - 若在筹办中发生违反 HFA 协议条款，ISSF 有权从中直接扣除罚金或违约金。

## 四、靶场技术规格、绿色环保与场馆验收门槛（Annex W.5）

申办场馆必须在提交标书时具备符合 ISSF 认证标准的硬件设施：

```
                                  [ 申办靶场硬件法定基准 ]
                                             │
      ┌──────────────────────────────┬───────┴──────────────────────┬──────────────────────────────┐
      ▼                              ▼                              ▼                              ▼
[ 10m 靶场: ≥ 60–80 靶位 ]   [ 25m 靶场: ≥ 8–10 组靶机 ]   [ 50m 靶场: ≥ 60–80 靶位 ]   [ 飞碟靶场: ≥ 4–5 个独立靶壕 ]
(全配认证 EST 靶机 + 双光路)  (全配 25m 速射翻转/电子靶)    (全配 50m 步枪三姿电子靶)    (配备 15 台抛靶机 + VAR 系统)
```

1. **光照度与温湿度强制标准**：
   - 资格赛靶面光照度：**≥ 1500 Lux**，决赛馆靶面光照度：**≥ 2000 Lux**（色温 5000K–6500K 无眩光）；
   - 室内 10 米气枪馆必须配备全天候新风与恒温系统（室内温度保持在 **18°C – 23°C**）。
2. **绿色环保与防铅认证（Environmental Homologation）** **【2026核心准入】**：
   - 飞碟靶场必须出具由举办国环保部核发的《土壤与地下水铅防渗工程验收合格书》；
   - 组委会必须书面承诺在比赛中**全额使用可生物降解无毒环保靶（Eco-friendly Clays）**，并与资质回收企业签署铅丸回收清运协议。

## 五、评审、现场考察与差额投票表决机制（Annex W.6）

1. **现场技术考察（Technical Inspection）**：
   - ISSF 选派由 2 名资深技术官员组成的评估团，赴申办城市进行为期 3 天的实地核验（差旅费用按规程由申办协会实报实销）；
   - 重点考察：靶场几何尺寸、主枪械库安保隔离、官方酒店承载力（至少 500 间三星级以上客房且距离靶场车程 **≤ 45 分钟**）、国际机场通关流线。
2. **差额投票与主办权核准**：
   - **世锦赛主办权**：由技术委员会初审 ➔ 执行委员会提出推荐名单 ➔ **ISSF 理事会（Council）或代表大会（General Assembly）无记名差额投票产生**；
   - **世界杯主办权**：由执行委员会主席团直接审议表决并核准公布。

## 六、违约制裁、擅自退赛与主办权剥夺规程（Annex W.7）

1. **擅自弃办制裁（Default & Withdrawal Penalty）** **【顶格罚则】**：
   - 主办国在签署 HFA 协议后擅自放弃办赛、或因政府担保违约导致赛事无法举办的：
     - **其缴纳的 €100,000 / €50,000 办赛保证金全额没收**；
     - 责令该联合会全额赔偿 ISSF、持权转播商及各参赛代表团已产生的实际差旅、集训及商业违约损失；
     - **暂停该国家协会未来 八（8）年 内申办任何 ISSF 国际赛事的资格**。
2. **主办权强制剥夺情形（Revocation of Hosting Rights）**：
   - 拒绝向特定受承认会员协会签发签证；
   - 无法提供主枪械库武装安保或枪支通关遭到海关实质性阻碍；
   - 靶场工程严重滞后，经赛前 6 个月复检被认定无法达标。

## 七、Annex W 世锦赛与世界杯申办规程速查总表

| **申办阶段 / 维度** | **法定标准与执行规范** | **责任主体 / 审批机构** | **对应条款** |
| :--- | :--- | :---: | :--- |
| **申办启动时限** | 世锦赛 **T - 4 年** 启动；世界杯 **T - 2 年** 启动 | 申办联合会 (NF) | Annex W.3.1 |
| **办赛保证金门槛** | 世锦赛 **€100,000 欧元**；世界杯 **€50,000 欧元**（现金/保函） | 申办协会 / ISSF 财务部 | Annex W.4.1 |
| **签证无障碍担保** | 必须提交外交/内政部签发的**全体会员无歧视入境签证保函** | 举办国政府部门 | Annex W.3.2(a) |
| **枪弹通关批文** | 赛前 60 天出具免税入境许可；机场直达枪库专业押运 | 举办国海关 / 警务部 | Annex W.3.2(b) |
| **靶位规模基准** | 10m/50m ≥ 60–80 靶；25m ≥ 8–10 组；飞碟 ≥ 4–5 靶壕 | 靶场建设方 / TD 验收 | Annex W.5.1 |
| **绿色环保门槛** | 强制提交水土铅防渗验收报告，**承诺全额使用无毒环保靶** | 场馆方 / 环保部门 | Annex W.5.2 |
| **主办权表决机构** | 世锦赛由**理事会差额投票决定**；世界杯由执委会核准 | ISSF 理事会 / 执委会 | Annex W.6.2 |
| **擅自弃办处罚** | **保证金全额没收**，赔偿全部实际损失，**禁办赛事 8 年** | ISSF 纪律与道德委员会 | Annex W.7.1 |
