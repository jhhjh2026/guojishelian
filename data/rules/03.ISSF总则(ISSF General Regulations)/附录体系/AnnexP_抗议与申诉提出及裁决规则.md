# ISSF 总则附件 P — 现场抗议与申诉裁决规程 (Annex P)

> **标准依据**：本文件依据 *ISSF Rule Book (Edition 2025 (Second Print 07/2026), Effective 1 July 2026)* 第 3 章《总则》（*General Regulations*）第 3.13.3.7 条法定附件 P（*Annex P — Rules for Filing and Deciding Protests*）以及《通用技术规则》第 6.16 条（*Protests and Appeals*）整理编制，系统规范赛事现场打分异议、计时抗议、判罚抵触、陪审团（Jury）现场仲裁、上诉陪审团（Jury of Appeal）终审程序、法定规费存退机制及 CAS 最终司法救济路径。

---

## 一、管辖架构与现场司法两级终审制

赛事现场争议处置严格实行**“基层专业陪审团初审 ➔ 上诉陪审团现场终审”**的两级审理架构：

```
[ 现场争议/判罚异议 ] ──> [ 向分项陪审团(Jury)提出抗议 (交纳 €50 现金) ]
                                      │
                                ┌─────┴─────┐
                                ▼           ▼
                           [ 抗议成立 ]   [ 抗议驳回 ] ──> [ 20分钟内向上诉陪审团(Jury of Appeal)申诉 (交纳 €100) ]
                           (退还 €50)                                       │
                                                                     ┌─────┴─────┐
                                                                     ▼           ▼
                                                                [ 申诉成立 ]   [ 申诉驳回 ] ──> [ 赛后提请 CAS 洛桑终审仲裁 ]
                                                                (退还 €100)   (没收 €100)
```

## 二、第一级：现场抗议提出规程与时限（Annex P.1 – P.3）

1. **口头即时异议（Verbal Protest）**：
   - 对靶位分配、射击时限口令下达、射击环境干扰有异议的，选手或随队官员必须在事件发生时**立即向靶位裁判（RO）口头提出**；
   - 若对 RO 处置结果不服，领队有权要求分项陪审团（Rifle/Pistol/Shotgun/RTS Jury）介入。
2. **书面正式抗议（Formal Written Protest）与时限**：
   - **手工打分/成绩册异议**：必须在初版官方成绩单（Preliminary Results）张贴/发布之日起 **十（10）分钟内** 提交；
   - **EST 电子靶分值质疑**：依据技术规则 6.16.5 处理，资格赛结束后立即由 RTS 陪审团提取日志与物理靶纸核对；
   - **器材违规判定异议**：在装备检查裁判下达不合规结论后 **十五（15）分钟内** 提交。
3. **法定抗议费（Protest Fee）** **【2026收费与退费标准】**：
   - 提交正式书面《抗议表》（Form P-1）时，必须同时以现金形式向陪审团缴纳 **50 欧元（EUR 50.00）**（或等值当地货币）；
   - **胜诉退还**：若陪审团判定抗议成立（Upheld），**50 欧元全额即时退还领队**；
   - **败诉没收**：若抗议被正式驳回（Denied），该费用全额没收并上缴 ISSF 发展基金。

## 三、第二级：上诉陪审团申诉终审规程（Annex P.4 – P.5）

1. **上诉陪审团组成与独立性（Jury of Appeal）**：
   - 由 3 至 5 名国际资深仲裁员组成，技术代表（TD）担任主席；
   - **严格回避原则**：任何曾参与一审判决的基层陪审团成员，或与涉案选手同国籍的委员，**一律强制回避**，不得参与合议。
2. **申诉时限与书面要求（Appeal Filing）**：
   - 领队若对基层陪审团的书面裁决不服，必须在裁决书送达之日起 **二十（20）分钟内**，向上诉陪审团提交书面《申诉书》（Form A-1）；
   - 必须载明申诉理由、违反的具体规则条款编号并附带现场佐证证据。
3. **法定申诉费（Appeal Fee）**：
   - 提交申诉时必须交纳 **100 欧元（EUR 100.00）** 现金；
   - 若申诉成功（胜诉），100 欧元全额退还；若申诉失败（败诉），费用没收。
4. **终局效力**：上诉陪审团作出的现场裁决为**该场锦标赛竞赛维度的终局决定（Final on Site）**，现场立即执行。

## 四、EST 电子靶打分争议特别处理规程 (Rule 6.16.5)

```
[选手质疑 EST 靶机未读数或读数偏差] ──> [不中断射击/打完全组] ──> [RTS 陪审团下载传感器原始数据]
                                                                          │
                                ┌─────────────────────────────────────────┘
                                ▼
         [ 调取见证卷带 (Witness Strip) 测量物理弹孔与传感器交叉比对 ]
                                │
               ┌────────────────┴────────────────┐
               ▼                                 ▼
      [ 存在传感器硬件故障 ]             [ 读数与物理弹孔一致 ]
      (判定为 AM / 执行补分或重射)      (维持原判 / 计驳回并收取抗议费)
```

1. **禁止现场触碰靶机**：在陪审团到达前，严禁任何人拔掉 EST 数据线、重启靶位机或触碰靶箱；
2. **物理弹孔优先比对**：当电子传感器信号存在丢发疑点时，以位于传感器后方匀速移动的**橡胶/纸质见证卷带（Witness Paper Strip）上的实际穿透物理弹孔中心坐标为最高判定基准**。
