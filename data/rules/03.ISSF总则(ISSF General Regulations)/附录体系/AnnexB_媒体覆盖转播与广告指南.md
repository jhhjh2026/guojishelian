# ISSF 总则附件 B — 媒体转播与广告规范 (Annex B)

> **标准依据**：本文件依据 *ISSF Rule Book (Edition 2025 (Second Print 07/2026), Effective 1 July 2026)* 第 3 章《总则》（*General Regulations*）第 3.13.3.12 条法定附件 B（*Annex B — Guidelines for Media Coverage, Broadcasting & Advertising*）整理编制，系统规范 ISSF 锦标赛电视转播制作标准（Host Broadcaster）、摄像机机位安全缓冲区、混合采访区（Mixed Zone）强制流线、电视转播画面广告边界及新媒体拍摄红线。

---

## 一、电视转播制作与主转播商（Host Broadcaster）标准（Annex B.1）

1. **主转播商法定职责（HB Obligations）**：
   - 必须提供符合国际奥委会奥林匹克转播服务（OBS）标准的超高清（4K HDR）国际公共信号（World Feed）；
   - 必须配备高速微距摄像系统（抓拍飞碟破碎瞬间）、射手心率实时遥测图形叠加系统及靶面实时电子弹着点三维轨迹图（3D Trajectory Graphic）。
2. **多语言解说席（Commentary Positions）**：
   - 决赛馆必须设立至少 6 个具备隔音屏障、独立音频链路及专用赛事数据监视器的持权转播商解说席位。

---

## 二、摄像机机位安全距离与射击专注力保护（Annex B.2）

为保障射击运动员的击发安全与超高专注力，电视转播机位部署必须严格遵守以下物理红线：

```
                                 [ 射手击发席位 / 靶位 ]
                                            │
                                  [ 1.5 米绝对安全缓冲区 ]
                                            │
                                ┌───────────┴───────────┐
                                ▼                       ▼
               [ 静音导轨 / 超长焦遥控云台 ]    [ 手持摄影师 (严禁使用闪光灯) ]
```

* **1.5 米绝对物理缓冲区（1.5m Buffer Zone）** **【2026核心红线】**：
  - 任何转播摄像摇臂、轨道车、收音麦克风或手持摄像师，**严禁侵入运动员射击席位周边 1.5 米的物理缓冲区**；
  - 摄像机移动轨道必须做全静音包胶处理，机械移动噪音在射手席位处测试**不得超过 45 分贝（dB）**；
* **光学限制（Lighting Restrictions）**：
  - 在资格赛与决赛全流程中，**严禁使用任何形式的机顶闪光灯、辅助对焦红光指示器或强光补光灯**直射射手面部或靶面。

## 三、混合采访区（Mixed Zone）强制流线与纪律（Annex B.3）

```
[ 决赛/资格赛结束 ] ──> [ 裁判宣布 RESULTS FINAL ] ──> [ 必须经由唯一通道进入混合采访区 ]
                                                                      │
                              ┌───────────────────────────────────────┘
                              ▼
        [ 第 1 梯队: 主转播商 (HB) 与持权电视机构 (5分钟直通专访) ]
                              │
        [ 第 2 梯队: 官方文字记者、国家通讯社及纸媒区 ]
                              │
        [ 第 3 梯队: 官方新媒体与社交网络拍摄区 ] ──> [ 签离离开 FOP 区域 ]
```

1. **强制通行原则（Mandatory Passage）** **【一票否决】**：
   - 所有参加比赛的运动员（无论晋级与否、是否获得奖牌），离开比赛场地（FOP）时**必须物理穿过混合采访区**；
   - 运动员无正当理由拒绝走过混采区或擅自跳跃护栏离开的，**处以通报批评并扣除 100 点个人世界排名积分**。
2. **持权优先原则**：
   - 采访顺序严格按“主转播商 ➔ 持权电视台 ➔ 官方通讯社 ➔ 认证平面媒体”依次排列；
   - 获奖运动员在混采区接受前三家持权媒体采访的总时间不得少于 10 分钟。

## 四、赛场视觉环境与电视广告尺寸控制（Annex B.4）

1. **靶面周边纯净区（Clean Zone）**：
   - 电子打分靶（EST）四周 2 米视野范围内，严禁放置任何商业赞助标识，保持纯净单色背景（通常为主办国浅灰或 ISSF 官方蓝）；
2. **赛场 A 字挡板广告（A-Boards Branding）**：
   - 位于射击席后方或观众席前沿的商业赞助 A 板广告，高度不得超过 **0.80 米**；
   - 广告板必须采用哑光防反光材质印刷，严禁使用高亮度 LED 跑马灯滚动屏（以防频闪干扰射手视觉瞄准）。
