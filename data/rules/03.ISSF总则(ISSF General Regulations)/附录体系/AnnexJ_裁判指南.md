# ISSF 裁判与技术代表（TD）资质认证与执照管理规程 (Annex J & Rule 3.13.3.9)

> **标准依据**：本规程依据 *ISSF Rule Book (Edition 2025 (Second Print 07/2026), Effective 1 July 2026)* 第 1 章《章程》（*Constitution*）第 1.8.2.5 条、第 3 章《总则》（*General Regulations*）第 3.13.3.9 条法定附件 J（*Annex J — Guidelines for Judges and Technical Delegates*）及 ISSF 裁判与技术代表联合认证规程整理，系统规范全球射击运动裁判员（Judges）及技术代表（Technical Delegates, TD）的准入分级、培训课时、理论与实操考核、执照周期审查及暂停/撤销处分规程。

---

## 一、管辖架构与执照分级体系（Classification & Hierarchy）

ISSF 裁判与技术官员资质认证实行全国联合会（NF）初筛推荐、ISSF 学院（ISSF Academy）与技术委员会统一组织培训考核、执行委员会（Executive Committee）核发的金字塔式分级体系：

```
                    ┌── [ TD 执照 ] (Technical Delegate): 国际大赛最高技术监督与协调决策
                    │
[ 执照层级体系 ] ───┼── [ J 级执照 ] (Judge Licence - A/B级): 国际赛事陪审团、主裁判长及执裁官
                    │     ├── A 级 (Master Judge): 奥运会/世锦赛陪审团(Jury)与各分项总裁判长
                    │     └── B 级 (International Judge): 国际赛事靶场裁判、检录官与器材检查官
                    │
                    └── [ C 级执照 ] (Candidate / Continental): 国家级骨干向国际级过渡之初级执照
```

### 1. C 级裁判执照（Continental / Candidate Judge Licence - Category C）
* **定位与职能**：作为国家级（National）高阶裁判向 ISSF 国际级裁判过渡的预备资质；
* **执裁权限**：获准在洲际锦标赛、地区大奖赛及国际邀请赛中担任助理靶场裁判、检录员、弹靶核对员及靶纸/数据统计员。

### 2. J 级国际裁判执照（Official ISSF Judge Licence - Category J [B / A]）
* **B 级国际裁判（Judge "B" Licence）**：
  - **执裁权限**：有权在所有 ISSF 管辖国际赛事（含世锦赛、世界杯、大奖赛）中独立担任靶位裁判（Range Officer, RO）、器材检查官（Equipment Control Officer, ECO）及决赛技术操作裁判；
* **A 级国际裁判（Judge "A" - Master Judge Licence）**：
  - **执裁权限**：有权担任奥运会、世锦赛、世界杯及洲际赛事的**陪审团成员（Jury Member）**、**分项总裁判长（Chief Range Officer, CRO）**及**器材检查陪审团主席**。

### 3. TD 技术代表执照（ISSF Technical Delegate Licence - TD）
* **定位与职能**：ISSF 派驻奥运会、世锦赛及各大洲锦标赛的最高现场技术监督与法律合规代表；
* **执裁权限**：全面监督赛场设施验收、靶机 EST 认证、抽签程序合法性、不可抗力技术裁决，并作为现场**最高安全保护官（Event Safeguarding Officer）**履行法定职责。

## 二、专项分科与准入前置条件（Disciplines & Prerequisites）

### 1. 专项执裁分科类别
裁判执照与 TD 认证严格按专业分项独立核发（一人可持多项，但须分别考核）：
* **R / P**：步枪与手枪专项（Rifle and Pistol）；
* **SH**：飞碟飞靶专项（Shotgun - Trap / Skeet）；
* **RT**：移动靶专项（Running Target）；
* **EST**：电子打分靶机与计分系统技术专科（Electronic Scoring Targets）；
* **EC**：器材与服装合规检测专科（Equipment Control）。

### 2. 报考前置准入红线（Prerequisites）
* **年龄与品行**：年满 **21 周岁**，身体健康（视力与听力满足执裁要求），且无任何刑事犯罪及严重违反体育道德记录；
* **国家级资质基础**：申请 C/B 级执照前，必须持有所属国家协会最高级别国家级裁判证书满 **三（3）年**，并附带不少于 10 场国家级锦标赛执裁履历日志（Logbook）；
* **官方推荐**：必须获得所属会员联合会（NF）主席或秘书长签发并加盖公章的正式书面推荐函。

## 三、官方培训课时与考核规程（Training Curriculum & Examination）

### 1. 法定培训课程学时要求
所有申请人必须全勤参加由 ISSF 执委会指派官方特级讲师授课的《ISSF 国际裁判官方认证培训班》：

```
┌─────────────────┬──────────┬──────────┬───────────────────────────────────────────┐
│  执照级别 / 类别 │ 理论学时 │ 实操学时 │              核心课程大纲模块             │
├─────────────────┼──────────┼──────────┼───────────────────────────────────────────┤
│ C 级裁判培训班  │ 16 学时  │  8 学时  │ ISSF通用总则、靶场安全口令、基础器材检测  │
│ B 级裁判考证班  │ 24 学时  │ 16 学时  │ 专项技术规则、EST故障裁决(6.17/8.9)、决赛 │
│ A 级晋升研讨班  │ 20 学时  │ 12 学时  │ 陪审团仲裁程序、突发争议听证、抗议与申诉  │
│ TD 技术代表研修 │ 30 学时  │ 15 学时  │ 场馆验收技术标准、赛程排期、危机干预与安全│
└─────────────────┴──────────┴──────────┴───────────────────────────────────────────┘
```

### 2. 理论闭卷考试与及格线（Written Examination）
* **考核形式**：统一采用闭卷笔试（或 ISSF Academy 监考在线考试系统），包含英文专业术语、规则情景案例分析及故障判定计算题；
* **合格分数线**：总分 100 分，**成绩达到 85 分及以上为及格通过**（低于 85 分者该期不予核发执照，且 12 个月内不得重考）。

### 3. 实操执裁考核（Practical Assessment）
* 在培训班配套的模拟实弹/电子靶测试赛中进行现场执裁测评，由两名及以上 ISSF 资深陪审团专家对以下项目进行独立打分：
  - 靶场标准英语口令（Commands）下达的准确性与威严度；
  - 遇到卡壳、底火未发火等突发故障（AM/UM）时的现场判定时效与动作规范；
  - 器材检测仪器（厚度计、刚度计、鞋底弯曲度规）的规范操作能力；
* 实操考核实行**一票否决制**：出现严重违背安全射击准则动作（如枪口对人未及时制止）者，直接判定为实操不合格。

## 四、执照晋升阶梯与业绩门槛（Licence Progression）

```
[国家级裁判] ──(满3年)──> [ C 级执照 ] ──(满2年+4场洲际赛)──> [ B 级国际裁判 ] ──(满4年+4场世锦/世界杯)──> [ A 级 Master ] ──(执委会遴选)──> [ TD 技术代表 ]
```

1. **C 级晋升 B 级条件**：
   - 持有 C 级执照满 **二（2）年**；
   - 在至少 **四（4）场** 洲际锦标赛或地区级国际赛事中完成执裁，且各场技术代表（TD）出具的执裁评估报告评级均为“优良（Satisfactory or above）”。
2. **B 级晋升 A 级条件**：
   - 持有 B 级执照满 **四（4）年**；
   - 在至少 **四（4）场** ISSF 世界杯、世锦赛、青年世锦赛或洲际顶级锦标赛中担任核心执裁官；
   - 经所属会员协会推荐并获 ISSF 技术委员会全体会议评审表决通过。
3. **TD 技术代表资格准入**：
   - 必须持有对应分项的 **A 级裁判执照满 三（3）年**；
   - 具备卓越的英语官方技术会议主持与组织协调能力；
   - 由 ISSF 执委会主席团直接提名并经执委会决议批准列入《ISSF 官方技术代表名录》。

## 五、执照全周期管理、年审与继续教育（CPD & Renewal）

1. **执照有效周期**：所有核发的 C 级、B 级、A 级裁判执照及 TD 资质有效期均为 **四（4）个自然年**（与奥运周期同步）。
2. **强制性继续教育学分（CPD / Refresher Courses）** **【2026红线要求】**：
   - 执照持有人在 4 年有效期内，必须通过 ISSF Academy 在线学习平台完成不少于 **16 学时** 的继续教育课程；
   - 课程必须涵盖：新周期规则重大技术修订（如 2026 新规）、EST 电子靶最新软件升级、反兴奋剂合规及《安全保护（Safeguarding）》反骚扰防虐待认证；
   - 未在执照到期日前 30 天完成规定学时者，**注册系统将自动锁定执照，禁止延期续证**。
3. **执裁活跃度考核（Activity Requirement）**：
   - 执照持有人在 4 年周期内，必须在至少 **两（2）场** 获 ISSF 认可的正式国际/洲际赛事中担任执裁工作；
   - 连续 **四（4）年** 无任何国际执裁记录且未参加继续教育者，其执照状态自动转为**“非活跃/失效（Inactive）”**，须重新参加 B 级考证班方可激活。

## 六、违纪处分、暂停与撤销撤职规程（Suspension & Revocation）

裁判员与技术代表在执业期间必须严格遵守《ISSF 诚信准则》与《职业道德守则》，任何违背职业操守的行为将受到严肃追责：

```
                         ┌── [ 警告 / 诫勉谈话 ]: 轻微执裁失误、未佩戴规定徽章或轻微迟到
                         │
[ 裁判违规处分阶梯 ] ───┼── [ 暂停执照 1–4 年 ]: 漏报利益冲突、重大执裁过失致赛果紊乱、违规饮酒
                         │
                         └── [ 永久吊销执照 ]: 索贿受贿、执裁打假/放水、泄露内幕信息、侵害未成年人
```

### 1. 执照暂停（Suspension of Licence）
有下列情形之一的，ISSF 纪律委员会可对当事人处以 **暂停执照 1 至 4 年** 的处分：
* 在执裁、检录或器材检查中存在重大过失，对比赛最终名次或奖牌归属造成严重不良后果；
* 未按《诚信守则》第四条规定主动书面申报利益冲突（如执裁直系亲属所属组别但未主动回避）；
* 赛事执裁期间在公共靶场区域饮酒、发表不当言论或损害 ISSF 官方形象；
* 受到所属国家协会或国家反兴奋剂机构纪律处分。

### 2. 执照撤销与终身禁入（Revocation & Permanent Ban）
凡发生下列重大/极端违纪行为者，ISSF 执委会将**直接吊销其全部裁判/TD执照，并在官方数据库中永久除名，终身不得重新申请**：
* 索取、收受参赛队或赞助商贿赂，参与操纵比赛胜负或比分；
* 利用裁判职务便利参与涉及射击比赛的地下博彩或向博彩集团提供内幕信息；
* 严重违反《安全保护规程》，对运动员（特别是未成年人）实施性骚扰、肢体暴力或精神虐待；
* 故意伪造裁判执裁日志（Logbook）、替考作弊或提供虚假证明材料。
