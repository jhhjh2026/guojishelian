# ISSF 总则附件 D — 运动员参赛合规声明与 ISSF ID 注册规程 (Annex D)

> **标准依据**：本文件依据 *ISSF Rule Book (Edition 2025 (Second Print 07/2026), Effective 1 July 2026)* 第 3 章《总则》（*General Regulations*）第 3.13.3.2 条法定附件 D（*Annex D — Athlete Declaration and ISSF ID Number Application Form*）以及《运动员资格总则》整理编制，全面确立全球射击运动员法定参赛声明签署、终身唯一识别码（ISSF ID）申请与核发、未成年人监护联签、国籍变更（转籍）三年等待期及 CAS 司法管辖确权规程。

---

## 一、运动员参赛合规声明（Athlete Declaration）法律性质与核心承诺

1. **法定强制前置（Mandatory Prerequisite）**：
   - 凡首次注册或代表所属国家/地区会员联合会（Member Federation）参加 ISSF 官方赛事（含奥运资格赛、世锦赛、世界杯、大奖赛及洲锦赛）的运动员，**必须在报名截止前签署官方《运动员参赛合规声明书》（Athlete's Declaration Form）**；
   - 未签署合规声明或声明失效者，ISSF 注册系统（RTS）将**物理锁定报名通道，严禁核发参赛证件（Accreditation）**。
2. **五大不可撤销之法定承诺条款**：
   - **反兴奋剂受检承诺**：承诺无条件恪守《世界反兴奋剂条例》（WADA Code）与《ISSF 反兴奋剂规则》，同意接受全球范围内 7×24 小时不事先通知的赛内及赛外兴奋剂尿样与血样采集；
   - **防范操纵与禁赌承诺**：严格遵守《奥林匹克运动防范操纵比赛准则》（OMPAC），严禁参与射击博彩，严禁故意消极比赛、操纵赛果或泄露内幕信息；
   - **安全保护与反虐待守则**：遵守《ISSF 安全保护规程（Safeguarding）》，杜绝任何形式的身体/心理虐待、性骚扰及霸凌行为；
   - **商业与赞助标识合规**：承诺在赛场、检录区、颁奖台等官方控制区严格执行《ISSF 商业与赞助广告规则》（Chapter 4）的尺寸与位置限制；
   - **CAS 排他性终局仲裁管辖**：**声明放弃任何本国或国际普通民事法院诉讼管辖权**，承诺将因参赛资格、纪律处分、反兴奋剂裁决及规则解释产生的一切争议，排他性提交国际体育仲裁法庭（CAS，瑞士洛桑）作终局仲裁。

## 二、未成年人监护人联签与有效性要求

1. **未成年人法定代理（Minor Athletes）** **【2026红线要求】**：
   - 签署声明当日未满 18 周岁（或所属国法定成年年龄）的青少年运动员，其声明表必须由其**法定监护人（父母或合法监护人）共同签署**；
   - 必须随附监护人有效身份证件复印件及法定监护关系证明文件。
2. **声明有效期与重新签署情形**：
   - 声明一经正式核准签署，在运动员持续持有有效注册状态期间原则上长期有效；
   - **出现以下情形时必须重新签署**：① 运动员年满 18 周岁由未成年人转为完全民事行为能力人；② 运动员发生国籍变更；③ ISSF 执委会决议发布新版全球合规声明总则时。

## 三、ISSF ID 终身识别码申领与全周期管理

```
[所属国家协会提交申请] ──> [上传签署声明书+护照扫描件] ──> [缴纳初次注册规费 €20] ──> [总部审核分配 10位 ISSF ID]
                                                                                            │
                                ┌───────────────────────────────────────────────────────────┘
                                ▼
[ 终身数据链绑定: 药检档案 / 世界排名积分 / 历史破纪录成绩 / 枪检合规台账 / 纪律处罚档案 ]
```

1. **终身唯一性原则（Lifetime Unique Identification）**：
   - 经审核分配的 10 位数 ISSF ID 伴随运动员整个竞技生涯直至退役，终身唯一且不可转让；
   - 该 ID 全程绑定该选手的历史比赛成绩、世界排名（World Ranking）、生物护照（ABP）、枪支器材合规检查记录及反兴奋剂药检数据。
2. **组别自动晋升机制（Age Category Transition）**：
   - 运动员在年满 **21 周岁当年的 12 月 31 日午夜**，系统将自动终止其青年组（Junior）参赛资格，其 ISSF ID 状态自动切换为成年精英组（Senior）；
   - 在青年组期间创造的青年世界纪录（QWRJ/WRJ）与积分将作为历史独立档案永久存证。

## 四、国籍变更与代表资格（Transfer of Allegiance）审查

1. **三年法定等待期（Three-Year Waiting Period）** **【核心准则】**：
   - 运动员变更国籍后代表新会员联合会参赛的，必须自其**代表原所属联合会参加的最后一场官方国际赛事的闭幕之日起，度过连续 三（3）年 的法定等待期**。
2. **等待期缩减与豁免程序（Reduction / Waiver）**：
   - 若原所属会员联合会出具由主席签署并加盖公章的《正式无异议豁免函》（Official Release Letter）；
   - 且新联合会与运动员共同向 ISSF 执行委员会提交书面缩减申请；
   - 经 ISSF 执委会评审批准，可将三年等待期**缩减至 一（1）年 或完全豁免**。
3. **地缘独立与新国家奥委会成立**：
   - 因联合国及国际奥委会（IOC）承认新国家成立或行政区划调整导致代表资格变更的，运动员须在 6 个月内向 ISSF 提交唯一书面选择声明，该选择权终身仅限行使一次。
