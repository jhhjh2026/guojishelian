# ISSF 总则附件 S — 飞碟裁判执裁与 VAR 规程 (Annex S / Edition 2026)

> **标准依据**：本文件依据 *Shotgun Jury Guidelines (Edition 2026, Effective 1 January 2026)*、*ISSF Rule Book (Edition 2025 (Second Print 07/2026), Effective 1 July 2026)* 第 3 章《总则》（*General Regulations*）第 3.13.3.10 条法定附件 S（*Annex S — Guidelines for Shotgun Referees*）以及第 9 章《飞碟规则》（*Shotgun Rules*, Rules 9.17 – 9.18）整理编制。系统规范飞碟多向（Trap）、双向（Skeet）项目主裁判（Referee）、边线助理裁判（Assistant Referees）的现场口令手势、中靶（Hit）与脱靶（Lost）裁决基准、黄红牌判罚阶梯及飞碟 VAR 视频回放系统复核规程。

---

## 一、飞碟裁判组配置与职权分工（Annex S.1 – S.2 & Jury Guidelines）

每组飞碟比赛现场必须配备由三人组成的现场执法裁判组：

```
                           ┌── [ 主裁判 (Referee) ]: 掌控抛靶控制台、鸣示中靶/脱靶、出示红黄牌、掌控赛场
                           │
[ 飞碟现场裁判三人组 ] ─────┼── [ 左边线助理裁判 (Left Assistant) ]: 观察左扇区微小碎片、观察踩线与出靶
                           │
                           └── [ 右边线助理裁判 (Right Assistant) ]: 观察右扇区微小碎片、复核计时与记分屏
```

1. **主裁判（Referee）核心法定职权**：
   - 佩戴官方计时与抛靶释放触发器，掌控出靶时限与序列；
   - 依据肉眼及边审信号，立即清晰大声下达 `"HIT"`（中靶）或 `"LOST"`（脱靶）法定指令；
   - 裁决枪支与弹药故障（AM/UM），下达 `"NO TARGET"`（无效靶/重放）口令；
   - 对违规行为出示黄牌警告（Warning）或红牌扣靶/除名判罚。
2. **边线助理裁判（Assistant Referees）法定职责**：
   - 站立于指定左右警戒观测位，手持中靶指示板（或红白旗）；
   - 当观察到肉眼可见的靶盘物理碎片脱落时，立即举牌/示意协助主裁判判定。

## 二、中靶（HIT）与脱靶（LOST）判定法定技术红线（Rule 9.17）

### 1. 法定中靶（HIT / Broken Target）判定红线
* 飞靶被射中后，裁判必须观察到**至少有 一（1）块 肉眼可见的实体碎片（Visible Piece）脱离靶体**；
* 仅产生粉尘、烟雾或荧光粉（Dust only）但**未掉落任何实体碎片者，一律判定为脱靶（LOST）**。

### 2. 双向飞碟（Skeet）预备姿势违规（Foot/Marker Violations）
* **枪托标志带红线**：选手在喊靶并出靶前，枪托底部凹角必须完全处于其衣服上缝制的黄色法定标志带（Marker Tape）以下；
* **提前举枪判罚**：在飞碟飞出前枪托提前上移的，主裁判立即中止并出示**黄牌警告（Warning）**；同一场比赛中再次违规，该靶直接判**脱靶（LOST）**。

## 三、飞碟 VAR 视频回放系统复核技术规程 (Rule 9.18 & VAR Manual)

在世锦赛、奥运会及世界杯决赛阶段，必须强制启用飞碟 VAR 视频助理裁判系统：

```
[选手对关键碎片判定异议] ──> [即刻向主裁举手示意申请 VAR 复核] ──> [暂停比赛/封锁靶壕]
                                                                        │
                                ┌───────────────────────────────────────┘
                                ▼
         [ 独立 VAR 裁判调取 3机位高速 1000fps 摄像机毫秒级逐帧复核 ]
                                │
               ┌────────────────┴────────────────┐
               ▼                                 ▼
      [ 确认存在可见物理碎片 ]           [ 仅有烟尘/无碎片脱落 ]
      (改判为 HIT / 保留挑战机会)        (维持 LOST 原判 / 扣除本场挑战机会)
```

1. **VAR 硬件技术参数**：
   - 靶壕扇区配备至少 3 台帧率 **≥ 1000 fps 的 4K 高速工业摄像机**；
   - 视角必须实现对中央主扇区、左极限 45° 与右极限 45° 抛靶轨迹的无死角全覆盖。
2. **挑战机会配额机制（Challenge Quota）** **【2026 决赛核心规范】**：
   - 每位进入决赛的选手在整场决赛中拥有 **一（1）次 初始 VAR 挑战机会**；
   - **挑战成功**：裁判改判，该选手保留该挑战机会；
   - **挑战失败**：维持原判，该选手的挑战机会即刻被扣除，整场比赛不再享有任何申诉视频复核权利；
   - 主裁判若自身对边缘碎片存在重大疑问，可**主动依职权启动 VAR 调查**（不计入选手挑战配额）。

## 四、违规行为判罚阶梯与纪律执行

| 违规性质 | 首次违规 | 第二次违规 | 严重/屡犯情节 |
| :--- | :--- | :--- | :--- |
| **迟到进入靶位** | 黄牌警告 (Warning) | 扣除当组第一靶 (LOST) | 直接取消该单项比赛资格 (DSQ) |
| **提前举枪 / 越线** | 黄牌警告 (Warning) | 该靶直接判脱靶 (LOST) | 累计扣除 2 靶并通报陪审团 |
| **装入多于规定弹药** | 立即终止并出示黄牌 | 判当靶脱靶并罚扣 1 靶 | 严重危害安全直接红牌驱逐 (DSQ) |
| **辱骂裁判 / 摔枪** | 直接出示红牌 (DSQ) | 永久驱离比赛场地 | 移交纪律委员会追加禁赛处分 |

## 五、Annex S 飞碟裁判执裁与 VAR 规程速查总表

| **执裁环节 / 维度** | **法定标准与执行规范** | **执裁人员 / 系统** | **对应条款** |
| :--- | :--- | :---: | :--- |
| **中靶判定红线** | 必须有**至少 1 块肉眼可见碎片脱落**；仅有烟尘判定为脱靶 | 主裁判 (Referee) | Rule 9.17.2 |
| **预备姿势标志带** | 枪托必须在黄色标志带下方；提前举枪二次违规直接判脱靶 | 主审 / 边审 | Rule 9.17.4 |
| **VAR 硬件配置** | 3机位、≥ 1000 fps 高速工业抓拍摄像机无死角覆盖 | 官方 VAR 仲裁室 | Rule 9.18.1 |
| **选手挑战配额** | 决赛每人限 **1 次挑战机会**；改判成功保留，失败扣除 | 决赛选手 / 主裁判 | Rule 9.18.3 |
| **安全红线违纪** | 严禁枪口对人或带弹转身，严重违规直接**出示红牌驱逐（DSQ）** | 靶场陪审团 (Jury) | Annex S.3.2 |
