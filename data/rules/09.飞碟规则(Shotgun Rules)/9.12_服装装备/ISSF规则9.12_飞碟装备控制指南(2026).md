# ISSF 飞碟装备控制指南（Edition 2026）

> **标准依据**：本文件依据 ISSF 官方指南 *Shotgun Equipment Control Guide (Edition 2026, Effective 1 January 2026)* 整理。该指南在**奥运会、世界锦标赛、世界杯与洲际锦标赛强制适用**（Compulsory），规范飞碟装备控制（EC）组织架构、检测器材与弹药抽检法定程序，配套《飞碟规则》Rule 9.4、9.12、9.17 执行。

---

## 一、装备控制组织（Chapter 1）

1. **总体原则（1.1–1.2）**：运动员仅可使用符合 ISSF 规则的装备服装；**任何可带来不公平优势、规则未明文提及或违背规则精神的枪械、装置与附件一律禁止**；任何用于**辅助计靶的附件、方法或系统一律禁止**——首次违反处**黄牌警告**，再犯**取消资格（DSQ）**（Rule 6.12.6.2 / 9.4.1 / 9.4.1.1 / 9.4.1.2）；
2. **责任分工（1.3）**：运动员对装备合规自负其责；装备控制仲裁委员会（EC Jury）负责检查，并须自**首个赛前训练日（PET）起提供装备控制咨询服务**供运动员自愿送检（Rule 9.4.1.1）；
3. **赛中抽检（1.4–1.5）**：仲裁在赛中实施随机抽查，枪械或双向标志带（Skeet Marker Tape）违规者可判 **DSQ**（Rule 9.4.1.1.D）；**赛场/射击区内的一切装备配件均视为该运动员可用物品**，均须接受检查并适用罚则（Rule 9.4.1.2）；
4. **开放安排（1.6）**：EC 地点与开放时间须在 PET 前一日及当日公布并送达各参赛国；**弹药检查（Cartridge Control）每日开放**；
5. **人员要求（1.7）**：咨询服务组至少由 EC 仲裁主席指定的 **2 名合格裁判**组成（或由主席亲自负责），须书面登记到场人员；宜陈列规则图示解释（1.8）；应为赛中被迫更改装备的运动员提供协助（1.9）；
6. **弹药检查专属权（1.10）**：弹药检查**仅由装备控制仲裁执行**，且须有 **1 名 ISSF 装备控制专家组成员在场**。

## 二、检测器材与枪支服装检查项（Chapter 2）

### 1. 工作准备（2.1–2.4）

- 按国别排列的运动员姓名与参赛号（Bib）名单；现行 ISSF 规则书；
- 检测合格封条/贴纸（宜带序列号）——**双向标志带必须使用带编号的 ISSF 封条并在标志带正面铆装小型空心铆钉**；
- 游标卡尺（测量枪管开孔与侧挡板）；**弹药检查必须使用 ISSF 全套标准检测工具（Full Test set）**。

### 2. 枪支检查项（Rule 9.4.2）

| 检查项 | 法定标准 | 规则 |
| :--- | :--- | :--- |
| 枪种 | 仅限滑膛猎枪；**禁止半自动与泵动式**；口径不得超过 **12 号**（小于 12 号可用） | 9.4.2 |
| 外观 | **不得为迷彩色涂装**；全部部件（开孔枪管、枪托、护木、枪管、可换喉缩）须由认可厂商制造，不合安全要求的改装禁用 | 9.4.2.1 |
| 扳机 | **严禁任何形式的"释放式"扳机（release trigger）** | 9.4.2.2 |
| 背带 | **严禁枪支背带/挂带（slings）** | 9.4.2.3 |
| **枪托高度（仅双向）** | 自贴腮板最高点量至托底板最低点 **≤ 170 mm**；非枪托整体构成、单纯加高托底的垂直延伸件禁用 | 9.4.2.9 |
| **枪管开孔** | 开孔自枪口或可换喉缩末端起算 **不得超过 200 mm** | 9.4.2.10（另见 9.4.2.6/.7） |
| 光学瞄具 | 严禁任何放大、发光、前置量显示、观察镜性质、摄像或增强目标视觉的装置 | 9.4.2.8 |

### 3. 服装与防护检查项（Rule 9.12 / 9.2.7）

| 检查项 | 法定标准 |
| :--- | :--- |
| **射击背心** | 比赛时必须穿着无袖射击背心或长袖射击上衣；**双向**背心不得含任何可调节合体度的构件（织带、抽绳、松紧带等），**不得使用任何弹性面料**；背心须带侧袋存放弹药，符合 GTR 6.7 与 6.20 着装规范 |
| 帽饰 | 仅正面和/或背面可缀国家、国家协会、ISSF 或赛事组委会徽章 |
| 鞋履 | 严禁露趾/露跟鞋、凉鞋类；**严禁赤足或仅穿袜射击**；不具运动外观的服装鞋帽配件一律禁止并由 EC 仲裁检查 |
| 服装通则 | 允许运动裤/训练服/运动裙服；**禁止蓝色牛仔裤及非运动色类似裤装、透明衣物**；短裤/裙下沿**不得高于膝盖骨中心 15 cm 以上**；袖长 **< 10 cm 或无袖上衣禁止**；**禁止迷彩面料**；电池加热服装须经 EC 仲裁批准 |
| **听力防护** | 射击线附近所有人员必须佩戴耳塞/耳罩；**含声音增强或接收功能的听力保护器**运动员与教练在赛场（FOP）禁用（听障运动员经仲裁批准除外，GTR 6.2.5） |
| **视力防护** | 所有运动员、裁判与官员必须佩戴防碎射击眼镜；**未戴听力/视力防护上岗：首次黄牌警告，同场赛事（含 PET）第二次处绿卡扣 1 靶**（扣减施加于资格赛第一轮首个命中靶）；因恶劣天气（雨雾）经仲裁主席宣布可免于佩戴射击眼镜 |

### 4. 双向标志带（Skeet Marker Tape，Rule 9.9.4.1 / 9.4.4）【双人检测法】

1. **仅允许使用 ISSF 官方标志带（250 mm × 30 mm）**，他种标志带一律禁用；赛中抽检发现违规**必须 DSQ**（Rule 9.15.5.1）；
2. **正确位置检测程序**：
   - 射击背心所有口袋须清空；
   - 运动员直立，持枪手（右手射手右臂）屈肘 90°——小臂水平、大臂垂直贴于体侧；
   - **两名仲裁共同检测**：一人站运动员**正前方**确认其肩部放松下沉，另一人站**体侧**观察肘部是否位于髋部标记上方；
   - 标志带正确位置＝**紧贴肘尖正下方**；
   - 合格后由仲裁在标志带末端加贴 **ISSF 封条**，并在标志正面铆装**小型空心铆钉**；
3. 标志带不合规者须**调整至正确位置并复检合格后方可参赛**。

### 5. 侧挡板与前挡板（Side Blinders，Rule 9.12.4）

- 仅飞碟运动员可用；附于帽、射击眼镜或头带上，**深度 ≤ 60 mm**；侧视时**前缘不得超过前额中心点前方 30 mm**；**仅限塑料材质**；**前挡板宽度 ≤ 30 mm**。

## 三、弹药规格与抽检程序（Chapter 3）

### 1. 霰弹法定规格（Rule 9.4.3 / 9.4.3.1）

| 项目 | 法定标准 |
| :--- | :--- |
| 铅弹丸重量 | **不得超过 24.0 g（+0.5 g 公差）**——以抽检弹的**平均重量 ≤ 24.5 g** 判定 |
| 弹丸形状/材质 | 球形；铅、铅合金或其他 ISSF 批准材料；可镀层 |
| 弹丸直径 | **≤ 2.6 mm** |
| 弹托（Wad） | 弹丸与发射药以外的一切抛出物**必须透明或半透明**；**弹丸不得加色**；不得添加任何可能被误认为命中靶的物质 |
| 禁用弹种 | 黑火药、曳光、燃烧及其他特种弹 |
| 内部改装 | 严禁可产生额外/特殊散布效果的内部改动（组件倒装、交叉装置等） |

### 2. 碟靶合规检测工具（Rule 6.3.6.1，ISSF 认证便携工具）

- 便携检测工具 + 工具证书；**0.8 N·m 扭矩螺丝刀**（附厂商校准证书）；**±0.1 g 数显天平**；**100 g M1 级校准砝码**；配件包（2 个支撑脚 + Ch10 扳手）；带 ISSF 标识便携箱。

### 3. 资格赛抽检程序（3.3）

- 受检运动员由**电脑抽签**产生，抽验比例为该项目参赛人数的 **10%–18%**；
- 取样须在赛场（FOP）内、射击开始前（该组/该轮开始前）进行；**除特殊情况外，不得在站位之间抽选**；
- 赛中裁判（依仲裁指示）或仲裁成员可随时对射击区内运动员的弹药取样检查（3.2）。

### 4. 决赛抽检程序（3.4）【时间节点红线】

1. **全员必检**：所有决赛选手**最迟于决赛开始前 30 分钟**到决赛靶场报到（Rule 9.17.3.1 / 9.18.4）；
2. **封箱程序**：仲裁指令决赛选手（或其教练/队官）将全部弹药放入**对应参赛号的编号箱**；EC 仲裁进行装备检查并取样后**封箱加封条**，封存箱由飞碟仲裁成员监管；弹药入箱后**仅 EC 仲裁或运动员本人（为进行决赛）可取出**；
3. **迟到罚则**：弹药未提前 30 分钟交验和/或运动员未按时报到，**从决赛首个命中靶成绩中扣 2 分**（Rule 9.17.3.1.B / 9.18.4.E）；
4. 封箱后不得再携弹进入 FOP；例外由装备仲裁决定并复测，且须在运动员亮相介绍开始前完成；**全部弹药检测必须在亮相介绍前完成**；运动员可不带装备离开 FOP，但**最迟须于开赛前 15 分钟返回**；
5. 若某决赛选手被取消资格，决赛以剩余选手进行（原文为 "five seven finalists"，系旧 6 人制文本修订残留，按 2026 八人决赛制理解为 **7 人**）；
6. 检测完成后 EC 仲裁在 FOP 当众开启编号箱，运动员须在场。

### 5. 双信封检测判定链（与 Annex A 表单配套）

```
  每名受检者取两组样品：信封①2 发（密封）＋ 信封②4 发（密封）
        │
        ▼ 检测前用【政府认证 24.5 g 标准砝码】校准天平
        │  （每次检出超重后须立即再次校准）
        ▼
  检查信封①（2 发）
        ├─ 两发均合法 ──► 不再处置，信封②退还运动员（PASS）
        ▼
  一发或两发超重（> 24.0 g + 0.5 g 公差）
        ▼
  开启信封②加测 4 发【须通知并邀请教练/队官到场见证】
        ├─ 六发总平均 ≤ 24.5 g ──► 合格
        ▼
  六发总平均仍超重 ──► DSQ（Rule 9.4.3.2 D），出示红卡
```

- **弹径检测**：必须使用 ISSF 弹径装置；不能通过装置的弹丸**必须用卡尺或千分尺全方向实测**，核查其圆度平均值；弹径不合格依 **Rule 9.4.3.1 d) 判 DSQ**；
- **弹托不合格**（不透明/加色弹丸）依 **Rule 9.4.3.1 f) 判 DSQ**；
- **钢珠检查**：以**磁铁**抽验钢质弹丸。

### 6. 弹药检查器材清单（Equipment Required）

- 弹药检查表（Cartridge Control Form，Annex A）；切弹器/开弹器；
- ISSF 弹径装置、游标卡尺或千分尺；
- 天平：数显至少两位小数，须持国家校准证书并配**政府认证 24.5 g 标准砝码**；
- 磁铁（钢珠检查）；A5 或类似规格信封；
- **8 个带盖透明箱（约 40 升）**，带封条固定孔。
