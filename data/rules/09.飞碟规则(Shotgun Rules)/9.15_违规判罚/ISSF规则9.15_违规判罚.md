# ISSF 飞碟违规判罚与梯度执法规则 (Rule 9.15)

> **标准依据**：本规则依据国际射击运动联合会《飞碟规则》（*ISSF Shotgun Rules, Edition 2025 (Second Print 07/2026), Effective 1 July 2026*）第 9.15 节（*Rule Violations*）整理编制，系统规范飞碟比赛违规行为的三大分类、裁决职权划分及三色牌（黄牌 Warning / 绿牌 Deduction / 红牌 Disqualification）梯度执法法定体系。

---

## 一、违规分类与裁决主体 (Rule 9.15 – 9.15.1)

### 9.15 违规行为三大分类
飞碟评审委员会（Jury）、首席裁判（Chief Referee）与当值主裁判（Referee）依据以下三类性质对违规行为进行裁决与定性：
- **1. “OPEN”（公开违规）** —— 直观、未掩盖的程序或着装违规；
- **2. “TECHNICAL”（技术违规）** —— 比赛动作、准备时限或射击技术层面的规则违规；
- **3. “CONCEALED”（隐蔽/恶意违规）** —— 蓄意、极其严重违反规则或危及 **靶场安全** 的恶性行为。

### 9.15.1 & 9.15.1.1 裁决职权与出牌原则
- **自由裁量权**：评审委员会负责审查并裁定所有上报违规的处罚轻重（规则明确规定由裁判自动执行的扣分除外）；
- **口令与卡牌必须同步**：出示判罚卡时，裁判必须配合清晰洪亮的英文口令：
  - **黄牌** ➔ 口令 **“Warning”（警告）**
  - **绿牌** ➔ 口令 **“Deduction”（扣分）**
  - **红牌** ➔ 口令 **“Disqualification”（取消资格）**
- **直接出牌原则**：**出示任何绿牌（扣分）或红牌（取消资格）之前，均无须先出示黄牌（警告）作为法定前置条件**。

---

## 二、警告（黄牌 Warning）(Rule 9.15.2)

### 9.15.2.1 公开违规情形（初犯出示黄牌）
首次出现下列公开违规情形时，由评审、首席裁判或主裁判出示 **黄牌警告** 并给予整改机会：
- **a)** 违反 ISSF 着装规定（Dress Code，如牛仔裤、非包裹性鞋类等）；
- **b)** 无正当理由擅自打断或拖延射击进程；
- **c)** 比赛进行中接受非法的场外指导（Illegal Coaching）；
- **d)** 未经许可擅自闯入比赛场地（FOP）；
- **e)** 出现非体育道德行为（Unsportsmanlike Conduct）；
- **f)** 蓄意规避规则精神（如利用非法配件计数）；
- **g)** 无意中错序击发（抢射 Out of Turn）；
- **h)** 在非授权区域进行空枪击发（Dry Firing）；
- **i)** 其他任何需要当场纠正的偶发事件。

### 9.15.2.2 – 9.15.2.4 整改与连带责任
- 运动员须在规定时限内改正违规；**逾期未改正者将直接施加扣分或禁赛处罚**；
- **教练/官员连带责任**：对于教练员或队伍官员的重复违规，评审有权责令其在 **本轮剩余时间内离开靶场周边区域**，且相关运动员可能受到连带纪律处罚。

## 三、技术违规类型与记分卡标注 (Rule 9.15.3 a–f)

比赛轮次中运动员首次出现下列技术违规时，主裁判当场出示 **黄牌警告**，并在官方记分卡送交 RTS 办公室前用官方指定缩写进行标注，同时提交《事故报告表》（Incident Report）：

| **官方缩写代码** | **技术违规行为** | **规则具体说明** |
| :---: | :--- | :--- |
| **FF** | **脚部犯规 (Foot Fault)** | 站位时脚部踩线或超出射击台界限 |
| **TL** | **时间限制违规 (Time Limit)** | 占据射位后超出规定时限呼靶（Trap 12秒 / Skeet 30秒） |
| **SKRP** | **双向准备姿势违规 (Skeet Ready Position)** | 呼靶时枪托底板高于黄色标记胶带或未贴紧身体 |
| **OG** | **单靶之间开枪机 (Opening the Gun)** | 双向 4 号位射击两发单靶之间擅自打开枪机（8 号位除外） |
| **FPG** | **随枪指向慢/快靶 (Following / Pointing)** | 遇慢抛/快抛目标时未射击却用枪跟踪指向飞碟轨迹 |

## 四、技术违规再犯扣分与弹药初犯 (Rule 9.15.3 g–h / 9.15.3.1)

### 9.15.3.1 技术违规再犯罚则（绿牌扣分）
- **扣分执行**：在比赛任何阶段（**决赛除外**），若运动员发生上述技术违规的 **第二次或后续同类违规**，当值裁判必须出示 **绿牌（Deduction）**，直接对该运动员处以 **扣 1 靶（扣 1 分）** 处罚；
  - **双向飞碟扣分点**：从该运动员该轮首个命中双靶中扣除；
  - **多向飞碟扣分点**：依据 Rule 9.8.4.6 直接判定该靶为 "LOST"；
- **执法口令程序**：裁判必须在运动员击发前大声命令 **“STOP”**，出示绿牌并明确告知处罚，现场调整记分板，随后指示下一位选手继续；
- **RTS 联动查验**：RTS 办公室有责任向各靶场裁判同步所有已记录的黄牌档案，确保跨轮次再犯扣分准确执行。

### 9.15.3 弹药常规不合格初犯
- 若运动员使用了不符合 Rule 9.4.3.1 规格的弹药（如弹丸微超、弹托透光度轻微不符等），初犯给予 **黄牌警告**。

## 五、严重违规扣分与擅自离场处置 (Rule 9.15.4)

### 9.15.4.1 由评审委员会裁决的扣分情形
经 **至少 2 名评审委员** 共同裁决，可从该运动员当前轮或前一轮的 **最后一个命中靶（Hit）中扣除 1 靶**：
- **a)** 以非体育道德方式故意干扰、妨碍另一名运动员；
- **b)** 在接受裁判/官员调查时，蓄意且明知地提供虚假信息（情节严重可直接取消资格）；
- **c)** 经黄牌警告后再次违规干扰、触碰靶场设备（抛靶机、麦克风等）；
- **d)** 使用不合格弹药的第二次或后续再犯；
  - **带色弹托重罚**：**使用带色弹托（Coloured Wads）者，再次违规直接扣除 5 靶（5 分）**（参见 Rule 9.4.1）；
- **e) 决赛报到迟到**：决赛运动员未按规定时间报到点名，**在决赛第一组命中成绩中扣除 2 靶（2 分）**。

### 9.15.4.2 未经许可擅自离场 (Leaving FOP)
- 运动员未完成本轮比赛且未经裁判许可擅自离开射击靶场者，经 **评审委员会多数表决**，**直接扣除该轮全部剩余未射飞碟的分数（剩余靶全部按 LOST 记 0 分）**。

## 六、取消比赛资格（红牌 Disqualification, DSQ）(Rule 9.15.5)

### 9.15.5.1 – 9.15.5.3 取消资格的裁决程序与成绩处理
- **裁决权限**：取消比赛资格必须由 **评审委员会（Jury）以多数表决通过**，由评审出示印有 **“Disqualification”** 的红牌执行；
- **全阶段成绩作废**：一旦被出示红牌取消资格，该运动员在该项比赛 **所有阶段（资格赛、加赛及决赛）的成绩全部作废清除**；
- **官方成绩单公示**：在成绩册末尾以 **“DSQ”** 标注，并在官方附注中详细载明被取消资格的具体原因条款。

### 9.15.5.4 必须处以取消资格（红牌 DSQ）的 8 大严重情形
- **a) 严重安全违规**：极其严重地违反靶场安全规程；
- **b) 危险用枪**：以极度危险的方式持握或操控霰弹枪（反复意外走火是重要考量因素）；
- **c) 停射指令后持闭合枪**：在裁判发出 “STOP” 指令后，依然手持或操作处于闭合状态的已上膛枪支；
- **d) 屡教不改**：重复发生此前已被出示黄牌（警告）或绿牌（扣分）的违规行为；
- **e) 辱骂侮辱官员**：故意辱骂、挑衅任何参赛队伍、靶场工作人员或赛事官员；
- **f) 恶意拒不补赛**：无正当理由蓄意拒绝补射此前被裁判批准的补赛轮次；
- **g) 蓄意虚假陈述**：在事故调查中恶意提供虚假信息企图隐瞒事实真相；
- **h) 恶意串通隐瞒**：蓄意包庇或隐瞒重大违规行为。

## 七、违规判罚梯度对照总表 (Rule 9.15)

| **违规行为 / 场景** | **执法级别与牌型** | **判罚处置与执行细节** | **规则依据** |
| :--- | :---: | :--- | :--- |
| **首次公开违规**（着装、非法指导、擅入、错序抢射、空放等） | **黄牌 (Warning)** | 当场警告并责令限时整改；逾期未改施加后续扣分 | Rule 9.15.2 |
| **首次技术违规**（脚踩线、呼靶超时、双向姿势、4号位开枪等） | **黄牌 (Warning)** | 记分卡标注对应代码（**FF / TL / SKRP / OG / FPG**）并报送 RTS | Rule 9.15.3(a)–(f) |
| **同类技术违规第二次及以后**（资格赛阶段） | **绿牌 (Deduction)** | **扣除 1 靶**（裁判喊 STOP、出绿牌、调大屏、记分卡记录） | Rule 9.15.3(g) |
| **使用不合格弹药（初犯）** | **黄牌 (Warning)** | 当场警告并责令更换合规弹药 | Rule 9.15.3.1 |
| **故意妨碍他人 / 干扰设备 / 提供假信息** | **绿牌 (Deduction)** | 至少 2 名评审裁定 **扣除 1 靶**（自最近轮次末个命中靶扣除） | Rule 9.15.4.1 |
| **使用带色弹托（Coloured Wads）再犯** | **绿牌 (Deduction)** | **直接重扣 5 靶（5 分）**（自最后 5 个命中靶中扣除） | Rule 9.4.1 / 9.15.4.1(d) |
| **决赛报到点名迟到** | **绿牌 (Deduction)** | 从决赛阶段 **首个命中成绩中扣除 2 靶（2 分）** | Rule 9.15.4.1(e) |
| **未完成本轮擅自离场** | **纪律扣分** | 评审多数裁定 **扣除该轮全部剩余未射靶数（全部记 0 分）** | Rule 9.15.4.2 |
| **严重安全违规 / 危险持枪 / STOP后持闭合枪 / 辱骂裁判 / 恶意欺瞒** | **红牌 (DSQ)** | 评审多数表决 **取消比赛资格**，全阶段成绩全部清零，标注 **DSQ** | Rule 9.15.5 |
