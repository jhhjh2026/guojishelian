# ISSF 飞碟决赛 VAR 视频助理裁判操作规范 (Rule 9.17.8–9.17.9)

> **标准依据**：本规范依据国际射击运动联合会《飞碟规则》（*ISSF Shotgun Rules, Edition 2025 (Second Print 07/2026), Effective 1 July 2026*）第 9.17.3.6 (j) 条及第 9.17.8 – 9.17.9 条（*Finals in Olympic Shotgun Events – VAR Procedures*）整理编制，系统规范飞碟奥运项目决赛中视频助理裁判（VAR）系统的技术配置、抗议发起、慢动作审阅流程、挑战次数限制及终局裁决效力。

---

## 一、VAR 官员与设备配置 (Rule 9.17.3.6 j) **【2026新增·VAR 站点与操作员配置】**

- **VAR 仲裁组与操作员（VAR Jury & Operator）**：决赛使用 VAR 系统时，由官方 VAR 技术操作员负责系统的运行与技术控制，操作专用慢动作回放控制台。负责的 VAR 评审委员监督系统全流程合规运行；
- **VAR 站点（VAR Station）**：设于比赛场地（FOP）指定安全区域，配备多角度高清慢动作回放专用监视器，**仅限当值主裁判、负责评委及 VAR 技术专家在审阅时使用**，严禁任何无关人员靠近。

---

## 二、VAR 抗议的发起程序 (Rule 9.17.8.1–9.17.8.3) **【2026新增·VAR 双轨发起与裁判电视手势】**

### 2.1 运动员本人发起 VAR 抗议 (Rule 9.17.8.1)
- 若运动员对裁判做出的 **“脱靶（LOST）”** 或 **“无效靶（NO TARGET）”** 判决持异议，**必须在下一名运动员击发之前** 立即举起手臂并大声呼叫 **“VAR”**，要求调用视频回放复核。

### 2.2 现场教练出示“VAR 卡”发起抗议 (Rule 9.17.8.2)
- 在 FOP 具备指定座席的教练，可在 **下一名运动员击发之前**，通过引起负责评审注意并出示官方发放的 **“VAR 卡”**（决赛前统一发放给全体教练）发起 VAR 抗议；
- 负责评审随即提请主裁判注意并启动 VAR 审阅程序。

### 2.3 比赛暂停与裁判法定电视手势 (Rule 9.17.8.3)
- VAR 抗议发起后，裁判必须立即下达 **“STOP”** 指令并暂停射击；
- 裁判须确保场上运动员清空霰弹枪开膛并面向观众区，同时**裁判面向观众区用双手在胸前比划出矩形电视屏幕轮廓（Video Screen Gesture）**，公开示意已启动 VAR 录像核查程序。

```
       [ 裁判双手在胸前比划矩形屏幕 ]
              ┌─────────┐
              │   VAR   │
              └─────────┘
        面向观众席公开宣告启动复核
```

## 三、VAR 视频审阅与最终裁决 (Rule 9.17.8.4 & 9.17.8.6) **【2026规范·慢动作审阅与主裁裁决权】**

### 3.1 审阅规程与裁决归属 (Rule 9.17.8.4)
- 主裁判与负责评审须一同前往 VAR 站点检视录像；
- 审阅在 VAR 系统专家（Technician）协助下进行，通过多角度超慢动作画面逐帧核对飞碟碎片脱落或飞行轨迹；
- **终审归属**：**慢动作审阅后的最终裁决权专属当值主裁判（The final decision after slow motion review rests with the Referee）**。

### 3.2 裁决宣布与法定手势动作 (Rule 9.17.8.6)
- 审阅完毕后，主裁判须面向观众席大声宣布最终裁决（**“HIT” / “LOST” / “NO TARGET”**）；
- 裁判须**再次比划矩形屏幕手势**，随后立即配合出示标准裁判手势（中靶 / 脱靶 / 重射），并在记分大屏上更新成绩。

---

## 四、VAR 抗议权限、次数限制与裁判主动调用 (Rule 9.17.8.5–9.17.9.1) **【2026规范·VAR 挑战次数与卡片管理】**

### 4.1 专属提交权限 (Rule 9.17.8.5)
- 运动员或教练 **仅可为其本人或本队所属运动员** 提交 VAR 抗议，**严禁对任何其他参赛对手的判罚发起 VAR 挑战**。

### 4.2 抗议挑战次数与 VAR 卡管理 (Rule 9.17.8.7–9.17.8.8)
- **挑战成功（原判被推翻）**：若首次 VAR 抗议被采纳（裁判改判），则自动保留发起第 2 次 VAR 抗议的权利。**每名运动员在整场决赛中最多允许提出两次（2 次）VAR 请求（A MAXIMUM OF TWO VAR REQUESTS ARE ALLOWED FOR EACH ATHLETE）**；
- **挑战失败（维持原判）**：若首次 VAR 抗议被驳回（维持原判），该运动员、教练或随队官员**不得再提出任何 VAR 抗议，其 VAR 卡由仲裁组当场收回并不予退还**；
- **裁判主动调用权 (Rule 9.17.8.9)**：主裁判若对判罚存疑，可个人主动调用 VAR，**不限次数（unlimited times）**，且不计入选手挑战额度。
- 
### 4.3 裁判主动调用 VAR 权能 (Rule 9.17.8.9)
- 主裁判在对靶位判罚（HIT / LOST / NO TARGET）存在疑问时，可 **主动依职权要求调用 VAR** 进行慢动作回放核实；
- 裁判主动调用 **不限次数**，且 **不计入运动员/教练的挑战限额**。

### 4.4 终局性效力原则 (Rule 9.17.9–9.17.9.1)
- VAR 系统的最终裁决为 **终局裁决，不得再向任何机构提起任何申诉或抗议（Final and not subject to appeal）**；
- 本规程无差别平等适用于决赛中的每一名参赛运动员。

## 五、飞碟决赛 VAR 操作规程速查总表 (Rule 9.17.8)

| **VAR 流程环节** | **法定操作规范与技术要求** | **执法主体 / 责任人** | **规则依据** |
| :--- | :--- | :---: | :--- |
| **发起时限红线** | **下一名选手击发之前**（举手喊 "VAR" 或出示 VAR 卡） | 运动员本人 / 指定教练 | Rule 9.17.8.1 / 9.17.8.2 |
| **叫停与公开手势** | 喊 "STOP"，运动员开膛面朝观众，裁判胸前**比划矩形屏幕手势** | 当值主裁判 | Rule 9.17.8.3 |
| **慢动作视频审阅** | 多角度慢动作回放逐帧核对；**主裁判享有最终裁定权** | 主裁判 + 评审 + 专家 | Rule 9.17.8.4 |
| **结果宣布与确认** | 再次比划屏幕手势 + 配合标准裁判手势宣布 HIT/LOST/NO TARGET | 当值主裁判 | Rule 9.17.8.6 |
| **挑战成功（改判）** | 保留 VAR 卡，可继续挑战（整场决赛单人上限 2 次） | 评审委员登记 | Rule 9.17.8.7 |
| **挑战失败（维持）** | **当场收回 VAR 卡**，该选手/教练全场丧失后续挑战权 | 评审委员收回 | Rule 9.17.8.8 |
| **裁判主动调用** | 裁判存疑主动调用，**不限次数**，不消耗选手挑战额度 | 当值主裁判 | Rule 9.17.8.9 |
| **裁决法律效力** | **终局裁决 (FINAL)**，严禁任何二次申诉或抗议 | 终局效力 | Rule 9.17.9.1 |
