# ISSF 飞碟裁判组（评审）工作指南 (Shotgun Jury Guidelines)

> **标准依据**：本指南依据国际射击运动联合会《飞碟规则》（*ISSF Shotgun Rules, Edition 2025 (Second Print 07/2026), Effective 1 July 2026*）第 9.5.2 节（飞碟评审职责）、第 9.17 节（8人决赛与 VAR 规程）、第 9.18 节（混合团体）及《附录 S：飞碟裁判与评审指南》（*Annex S*）整理编制，系统规范飞碟评审委员会（Shotgun Jury）在赛前靶场参数验收、抛靶机雷达测速标定、赛中巡查抽检、正式申诉听证、重大判罚（DSQ）终审及决赛 VAR 与教练暂停监督等全流程法定执裁规程。

---

## 一、飞碟评审委员会组织架构与岗位职责（Jury Staffing & Roles）

1. **人员编制与着装规范（Rule 9.5.1 & 9.5.2）**：
   - **评审委员会（Shotgun Jury）**：由持有有效 ISSF A 级或 B 级飞碟裁判执照的资深官员组成（通常设 3 至 5 名，含 1 名评审主席）；
   - **法定着装**：评审委员执勤时**必须统一穿着 ISSF 官方红黑双色评审背心（Red and Black Jury Vest）**；
   - **与现场官员的分工界线**：
     - 主裁判（Referee）与助理裁判（Assistant Referee）负责靶场**即时的单发判决（HIT/LOST/NO TARGET）与安全口令**；
     - 评审委员会负责**全场技术监督、规则解释、申诉终审、抽查检验及纪律制裁**。
2. **核心岗位职责细分**：
   - **评审主席（Jury Chairperson）**：全面统筹评审团排班、主持正式申诉听证合议、签署批准官方成绩单、提交赛后技术总结报告；
   - **当值负责评审（Jury Member-in-Charge）**：具体进驻当值靶场或决赛馆，受理现场口头抗议，掌控教练暂停（Time-out）计时，监督 VAR 录像复核流程；
   - **VAR 专项评审（VAR Jury Member）** **【2026规范·VAR专属监督】**：与 VAR 系统操作员一同值守 VAR 站点，协助主裁判进行慢动作逐帧回放与卡片管理。

## 二、赛前场地技术验收与抛靶参数标定（Range & Target Verification）

```
                        【飞碟赛前技术验收法定工作流】
                                     │
           ┌─────────────────────────┼─────────────────────────┐
           ▼                         ▼                         ▼
  【靶场几何与安全检查】     【多向/双向抛靶参数标定】     【陷阱坑与靶房锁定封签】
  • 站位界线与安全距离       • 多普勒雷达初速校核 (Radar)  • CRO 配合上锁
  • 挡弹墙与防眩背景         • 抛射距离与仰角夹角核准      • 严禁无关人员进入
  • 闪光靶(Flash)库存核实    • 抽检泥靶重量与易碎度        • 填写签发《参数核准单》
```

### 2.1 多向飞碟（Trap）验收与抛靶方案标定（Rule 9.8.3）
1. **15 台抛靶机参数核验**：
   - 依据技术代表（TD）抽签确定的官方抛靶方案（Schemes 1–9），逐一核验 5 个靶组、共 15 台抛靶机的**抛射高度（10米处 1.5m–3.0m）、水平夹角（中心线向左/向右最大 45°）及飞行距离（76.0m ± 1.0m）**；
2. **多普勒雷达测速（Doppler Radar Verification）** **【现代科技标定】**：
   - 评审团使用经官方校准的多普勒测速雷达，在靶口前方测量飞碟初始飞行速度（标准初速通常为 **80–85 km/h**），确保同组内各抛靶机出靶动能完全一致；
3. **陷阱坑（Trap Pit）安全封存**：
   - 参数校准完毕后，评审主席会同首席靶场长（CRO）**对陷阱坑出入口加锁并施加封签**，非经评审许可，赛前赛中严禁任何人擅入调动参数。

### 2.2 双向飞碟（Skeet）验收与标定（Rule 9.9.3）
1. **高低靶房弹道与交会点核验**：
   - 飞碟飞行距离自靶房抛口起算严格为 **68.00m ± 1.00m**；
   - 两靶飞行轨迹必须穿过 **8 号射击位正上方 4.60m（±0.15m）** 处的空间交会圆环（Crossing Point Marker Hoop）；
2. **声控延迟装置抽检**：
   - 检查声控释放系统在呼靶后的随机延时必须稳定在 **0.0 至 3.0 秒**（电子设备公差为 0.2 至 3.0 秒）范围内。

## 三、比赛期间日常巡查与监控规程（Field of Play Monitoring）

### 3.1 运动员装备与着装赛中抽检（Rule 9.4 & 9.9.4）
- **双向标记带（Marker Tape）巡查**：
  - 评审在赛中须持续动态监视运动员的 READY 预备姿势，核验射击背心上的黄色官方标记带（250×30mm）位置是否处于肘尖水平线下方，封条与金属铆钉是否完好；
  - **凡私自改动标记带位置或穿着含弹力面料背心者，评审必须当场提请取消比赛资格（出示红牌 DSQ）**；
- **侧挡片（Side Blinders）与护目镜**：
  - 检查侧挡片是否符合深度 ≤ 60mm、前突 ≤ 30mm 的塑料材质安全防护标准（Rule 9.13.4）；
- **霰弹弹药重量与规格抽检**：
  - 评审有权在射击站位随时抽取运动员用弹，现场核验铅弹丸总重（**严格 ≤ 24.50g**）、弹丸直径（**≤ 2.60mm**）及无色透明弹托。

### 3.2 准备时限电子秒表抽查（Preparation Time Limits）
- **多向飞碟**：当值选手进位、装弹并呼靶必须在 **12 秒** 内完成（Rule 9.8.2.3）；
- **双向飞碟**：进位时限 **10 秒**，站位全套呼靶总时限 **30 秒**（Rule 9.9.2.1）；
- **抽查执罚程序**：评审员在靶位后方使用秒表抽测，超时初犯提请裁判出示**黄牌警告**；同场同项目再次超时，由主裁判定为 **"LOST"**。

## 四、抗议受理、听证与重大裁决程序（Protests & DSQ Protocol）

```
                     【飞碟争议与正式申诉（Protest）处理流线】
                                       │
            ┌──────────────────────────┴──────────────────────────┐
            ▼                                                     ▼
   【靶位判定口头异议】                                  【程序性/纪律性正式抗议】
   • 限下一名击发前提出                                  • 赛后 10–20 分钟内递交 Form P
   • 主裁判做出 HIT/LOST/NO TARGET 判定                 • 附交抗议费（资格赛 EUR 50.00）
   • 或依据 9.17.8 启动 VAR 复核（决赛）                 • 评审委员会召开闭门听证会议
            │                                                     │
            ▼                                                     ▼
   【终局裁决：不得上诉】                                 【合议表决，出具正式书面裁决】
                                                         • 胜诉：退款并修正结果
                                                         • 败诉：没收规费并维持原判
```

### 4.1 口头异议与 VAR 规程的现场衔接（Rule 9.17.7 & 9.17.8）
1. **靶面判决异议时效红线**：
   - 运动员对“HIT / LOST / NO TARGET”有异议，**必须在下一名运动员击发之前**举手示意；下一人击发后提出的异议一律无效；
2. **决赛非靶型抗议驳回扣 2 分罚则（Rule 9.17.7 d）**：
   - 决赛阶段若就程序问题向 3 人决赛抗议评审组提起抗议且被驳回，**必须直接从该运动员最后两（2）个命中靶中扣除 2 分（-2 Hits）**；
3. **VAR 挑战与卡片管理（正本第 439 页，Rule 9.17.8.7–9.17.8.8）**：
   - 负责评审必须准确记录选手的 VAR 使用次数（**每人每场上限 2 次**）；
   - 首次挑战失败（维持原判）时，**当场收回教练持有的“VAR 卡”并不予退还**，该选手/教练即刻丧失后续所有挑战权。

### 4.2 取消比赛资格（DSQ）唯一裁决权（Rule 9.5.2.2 j / 9.5.5.5）
- **权能硬隔离**：**当值主裁判（Referee）无权直接做出取消比赛资格（DSQ）的判决**；
- **法定程序**：遇严重违反安全操作、使用违规弹药、标记带作弊、赛后抽检不合格或严重违背体育道德行为时，主裁判必须暂停比赛并上报评审委员会；
- 评审委员会经核查取证后，由评审主席或全体多数表决正式签发 **出示红牌（Red Card）取消比赛资格（DSQ）**。

## 五、决赛监督与教练暂停控制（Finals & Coaching Time-out SOP）

### 5.1 8 人决赛运行与平局判定监督（Rule 9.17）
1. **起始号牌与成绩重置核查**：
   - 确保晋级 8 人决赛选手的资格赛成绩完全清零（Start from zero），按 1–8 号起始号牌就位；
2. **3 至 8 名淘汰平局依号牌打破**：
   - 淘汰节点出现并列时，严格监督系统依起始号牌（号码小者胜出）直接排定名次，**严防现场组织不必要的加赛**；
3. **冠亚军加赛（Shoot-off）即时开启**：
   - 第 1、2 名总分相同，监督主裁立即组织加赛（多向 1–5 循环单发 / 双向 4 号位常规与反向双靶），不设试靶。

### 5.2 决赛教练暂停（Coaching Time-out）执裁控制（Rule 9.18.4）
- **申请受理**：FOP 内指定席位教练向当值负责评审举手申请暂停（每场比赛限 1 次）；
- **介入时机**：负责评审在该队射击间隙暂停比赛，允许教练上前；
- **共享暂停控制（Shared Time-out）**：其他队伍教练亦可同时上前指导（不消耗自身暂停次数）；
- **精准计时与口令**：评审员严格掐表 **30 秒至 1 分钟**，时限一到立即大声下达 **“TIME”** 指令，强制全体教练返回坐席。

## 六、飞碟评审执裁工作清单与速查总表

| 工作阶段 / 环节 | 评审核心监控要点 | 关键技术标准 / 执法红线 | 对应条款 |
| :--- | :--- | :--- | :--- |
| **赛前场地验收** | 抛靶高度、夹角、距离与初速 | 多向 76m±1m (雷达测速)；双向 68m±1m | Rule 9.8.3 / 9.9.3 |
| **靶房与陷阱坑管理** | 验收后锁定封存 | 联合 CRO 施加物理锁与封条，严防调参 | Rule 9.5.3.3 h |
| **赛前装备检查服务** | 设立 EC 咨询台 | 检查背心、标记带位置、测厚、枪支尺寸 | Rule 9.5.2.1 d |
| **双向标记带赛中抽测** | 骨盆髂骨量规复查 | 严禁弹力背心，标记带过高**直接判 DSQ** | Rule 9.9.4.3 / 9.9.4.4 |
| **霰弹弹药抽检** | 称重、测径、弹托透明度 | 铅重 **严格 ≤ 24.50g**；弹丸直径 **≤ 2.60mm** | Rule 9.4.3.1 / 9.4.3.2 |
| **准备时限抽查** | 电子秒表后台监控 | 多向 ≤ 12s / 双向 ≤ 30s；再犯判 **"LOST"** | Rule 9.8.2.3 / 9.9.2.1 |
| **VAR 复核监督** | 控制台与 VAR 卡管理 | **每人上限 2 次**；首诉驳回收回 VAR 卡 | Rule 9.17.8 (p. 439) |
| **教练暂停监管** | 掐表 30秒–1分钟 | 启动共享机制；评审喊 "TIME" 强制离场 | Rule 9.18.4 |
| **重大纪律判罚** | 取消比赛资格（DSQ） | **专属于评审委员会全体合议表决签发** | Rule 9.5.2.2 j |
